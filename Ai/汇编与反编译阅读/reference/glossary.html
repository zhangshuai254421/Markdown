汇编阅读术语表

只收录为了读 Windows x64 C++ 反编译必须稳定掌握的词。

+
术语阅读时的含义
寄存器CPU 内部的少量高速位置。反编译时把它先视为临时变量或参数槽位，不要赋予“变量名”含义。
RIP下一条指令的位置；条件跳转改变它，从而实现 if、循环、switch。
RSP当前栈顶指针。sub rsp, ... 通常是为局部数据或调用预留栈空间。
RBP可选的帧指针。优化后常被当作普通非易失寄存器，不能机械地把它等同于“栈帧”。
内存操作数[rcx+8] 表示地址 rcx + 8 指向的内存。对 C++ 常可先猜为对象字段，再用交叉引用验证。
基本块一段从入口顺序执行到分支/返回的指令。读函数时先读块和边，再读每条指令。
调用约定 / ABI调用方和被调函数对参数、返回值、栈和寄存器保存的共同协议。
易失寄存器调用后可被覆盖；不能假定 call 后仍保留原值。
非易失寄存器被调函数若使用，必须恢复；常承载跨调用仍需存活的值。
Shadow spaceWindows x64 中由调用方始终为前四个参数槽预留的 32 字节栈空间；它不是自动等于四个业务局部变量。
RAX / EAX常见的标量返回值寄存器；EAX 是 RAX 的低 32 位。
XMM0常见的浮点/向量返回值寄存器；前四个浮点参数按位置在 XMM0–XMM3。
