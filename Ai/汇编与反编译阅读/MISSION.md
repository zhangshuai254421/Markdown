# Mission: 汇编与 C++ 反编译阅读

## Why

把零散阅读过、容易遗忘的汇编知识变成一套稳定的阅读方法。遇到 Windows x64 下的 C++ 反编译或反汇编时，能够将其还原为熟悉的变量、分支、循环、调用和对象访问，从而能独立追踪程序行为。

## Success looks like

- 能为一个小型 C++ 函数标出参数、返回值、局部变量、分支和循环。
- 能解释 Windows x64 调用点与被调函数之间的寄存器、栈和返回值流动。
- 能在 Ghidra 的反编译结果与汇编之间交叉验证，并识别优化或工具推断带来的不确定性。

## Constraints

- 有 10 年 .NET 工程经验，已有零散阅读经历。
- 以 Windows x64、MSVC 风格 C++ 为主；课程短小、练习导向。

## Out of scope

- 手写汇编、操作系统/内核开发、漏洞利用和极限性能调优。
- ARM、x86-32、Linux System V ABI 的系统学习。
