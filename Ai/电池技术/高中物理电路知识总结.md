## 1. 基本概念

### 1.1 电流（I）

| 项目 | 内容 |
|------|------|
| **定义** | 电荷的定向移动形成电流 |
| **方向** | 规定**正电荷定向移动的方向**为电流方向（金属导体中电子移动的反方向） |
| **公式** | $I = \frac{q}{t}$ |
| **单位** | 安培（A），1A = 1C/s |
| **微观表达式** | $I = nqSv$ |

> **说明：** $n$ — 单位体积内自由电荷数；$q$ — 每个自由电荷的电量；$S$ — 导体横截面积；$v$ — 电荷定向移动速率

**注意：**
- 电流是**标量**，但有方向（规定正电荷运动方向为正方向）
- 形成电流的条件：① 有自由电荷；② 有电势差（电压）

### 1.2 电压（U）

| 项目 | 内容 |
|------|------|
| **定义** | 电场中两点间的电势差，是使电荷定向移动形成电流的原因 |
| **公式** | $U = \frac{W}{q}$ |
| **单位** | 伏特（V），1V = 1J/C |

### 1.3 电阻（R）

| 项目 | 内容 |
|------|------|
| **定义** | 导体对电流的阻碍作用 |
| **单位** | 欧姆（Ω） |
| **物理意义** | 反映导体导电性能的物理量，由导体本身性质决定 |

## 2. 欧姆定律

### 2.1 部分电路欧姆定律

> **内容：** 导体中的电流与导体两端的电压成正比，与导体的电阻成反比。

$$I = \frac{U}{R}$$

| 变形式 | 含义 |
|--------|------|
| $U = IR$ | 已知电流和电阻求电压 |
| $R = \frac{U}{I}$ | **注意：** 这是电阻的定义式/测量式，不是决定式。R由导体本身决定，与U、I无关 |

### 2.2 I-U 图像（伏安特性曲线）

```
    I ↑
      │      ╱  (线性元件：电阻恒定)
      │    ╱
      │  ╱
      │╱
      └──────────→ U
      O
```

- **线性元件：** I-U 图像为过原点的直线，斜率 $k = \frac{1}{R}$，电阻恒定
- **非线性元件：** I-U 图像为曲线（如二极管、灯泡），电阻随电压/电流变化
- **U-I 图像：** 斜率为 $R$（注意区分 I-U 和 U-I 图像）

### 2.3 欧姆定律适用条件

- 适用于**金属导电**和**电解液导电**
- 不适用于气体导电和半导体元件

## 3. 电阻定律与电阻连接

### 3.1 电阻定律

$$R = \rho \frac{l}{S}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $\rho$ | 电阻率（由材料决定） | Ω·m |
| $l$ | 导体长度 | m |
| $S$ | 导体横截面积 | m² |

### 3.2 电阻率 $\rho$

- **物理意义：** 反映材料导电性能的物理量
- **与温度的关系：**
  - 金属：$\rho$ 随温度升高而**增大**（正温度系数）
  - 半导体：$\rho$ 随温度升高而**减小**（负温度系数）
  - 某些合金（如锰铜、康铜）：$\rho$ 几乎不受温度影响 → 用于制作标准电阻

### 3.3 超导现象

当温度降到某一特定温度（临界温度）以下时，某些材料的电阻突然降为零。

## 4. 串联电路与并联电路

### 4.1 串联电路

```
  ┌───[R₁]───[R₂]───[R₃]───┐
  │                         │
  └─────────[电源]──────────┘
```

| 项目 | 规律 |
|------|------|
| **电流** | $I = I_1 = I_2 = I_3 = \cdots$（处处相等） |
| **电压** | $U = U_1 + U_2 + U_3 + \cdots$（总电压等于各分压之和） |
| **电阻** | $R = R_1 + R_2 + R_3 + \cdots$（总电阻等于各电阻之和） |
| **电压分配** | $\frac{U_1}{R_1} = \frac{U_2}{R_2} = \cdots = I$（电压与电阻成正比） |

### 4.2 并联电路

```
  ┌──────────────────────────┐
  │    ┌───[R₁]───┐          │
  ├────┤          ├──────────┤
  │    └───[R₂]───┘          │
  └─────────[电源]───────────┘
```

| 项目 | 规律 |
|------|------|
| **电压** | $U = U_1 = U_2 = U_3 = \cdots$（各支路电压相等） |
| **电流** | $I = I_1 + I_2 + I_3 + \cdots$（总电流等于各支路电流之和） |
| **电阻** | $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + \cdots$ |
| **电流分配** | $I_1R_1 = I_2R_2 = \cdots = U$（电流与电阻成反比） |

### 4.3 串并联对比

| 比较项 | 串联 | 并联 |
|--------|------|------|
| 电流 | 各处相等 | 干路电流 = 各支路电流之和 |
| 电压 | 总电压 = 各部分电压之和 | 各支路电压相等 |
| 总电阻 | 大于任一部分电阻 | 小于任一支路电阻 |
| 功率分配 | $P \propto R$ | $P \propto \frac{1}{R}$ |

### 4.4 分压器与分流器

- **分压（串联）：** $U_1 = \frac{R_1}{R_1 + R_2} \cdot U$
- **分流（并联）：** $I_1 = \frac{R_2}{R_1 + R_2} \cdot I$

## 5. 电功与电功率

### 5.1 电功（W）

$$W = UIt$$

| 单位 | 换算 |
|------|------|
| 焦耳（J） | 1J = 1V·A·s |
| 千瓦时（kW·h） | 1kW·h = 3.6 × 10⁶ J |

> 电流做功的本质：电场力移动电荷做功，电能转化为其他形式的能。

### 5.2 电功率（P）

$$P = \frac{W}{t} = UI$$

- **单位：** 瓦特（W），1W = 1J/s
- **额定功率：** 用电器在额定电压下正常工作时的功率
- **实际功率：** 用电器在实际电压下工作时的功率

### 5.3 纯电阻电路中的功率公式

对于**纯电阻电路**（电能全部转化为内能）：

$$P = UI = I^2R = \frac{U^2}{R}$$

| 公式 | 适用场景 |
|------|----------|
| $P = UI$ | **普遍适用** |
| $P = I^2R$ | 常用于串联电路（I相同） |
| $P = \frac{U^2}{R}$ | 常用于并联电路（U相同） |

### 5.4 纯电阻电路 vs 非纯电阻电路

| 电路类型 | 能量转化 | 适用公式 |
|----------|----------|----------|
| **纯电阻电路**（电炉、白炽灯） | 电能 → 内能（全部） | $W = UIt = I^2Rt = \frac{U^2}{R}t$ |
| **非纯电阻电路**（电动机、电解槽） | 电能 → 内能 + 机械能/化学能 | $W = UIt$（总功），$Q = I^2Rt$（发热） |

> **关键区别：** 非纯电阻电路中，$UIt > I^2Rt$，因为部分电能转化为了非内能形式。

## 6. 焦耳定律

### 6.1 内容

> 电流通过导体产生的热量与电流的平方、导体的电阻和通电时间成正比。

$$Q = I^2Rt$$

- 这是计算**任何电路**中发热量的**普遍公式**

### 6.2 热功率

$$P_{\text{热}} = I^2R$$

- **纯电阻电路：** $P_{\text{总}} = P_{\text{热}} = UI = I^2R = \frac{U^2}{R}$
- **非纯电阻电路：** $P_{\text{总}} = UI$，$P_{\text{热}} = I^2R$，$P_{\text{总}} > P_{\text{热}}$

## 7. 闭合电路欧姆定律

### 7.1 基本概念

```
    ┌──────────────────────────┐
    │    外电路（R → 路端电压U）  │
    ├──── ── ── ── ── ── ── ──┤
    │    E（电动势）  r（内阻）   │
    └──────────────────────────┘
```

| 概念 | 符号 | 含义 |
|------|------|------|
| **电动势** | $E$ | 电源将其他形式能转化为电能的本领，在数值上等于非静电力把1C正电荷从负极移到正极所做的功 |
| **内阻** | $r$ | 电源内部的电阻 |
| **路端电压** | $U$ | 外电路两端的电压，$U = E - Ir$ |

### 7.2 闭合电路欧姆定律

$$I = \frac{E}{R + r} \quad \text{或} \quad E = U + Ir$$

| 形式 | 公式 |
|------|------|
| 电流形式 | $I = \frac{E}{R + r}$ |
| 电压形式 | $E = U_{\text{外}} + U_{\text{内}} = IR + Ir$ |
| 路端电压 | $U = E - Ir$ |

### 7.3 路端电压与负载的关系（U-R 关系）

$$U = \frac{E}{1 + \frac{r}{R}} = \frac{ER}{R + r}$$

- 当 $R \to \infty$（断路）：$U = E$（路端电压等于电动势）
- 当 $R = 0$（短路）：$U = 0$，$I_{\text{短}} = \frac{E}{r}$（短路电流）
- $R$ 增大 → $U$ 增大；$R$ 减小 → $U$ 减小

### 7.4 U-I 图像（路端电压-电流图像）

```
  U ↑
    │
  E ┤╲
    │  ╲
    │    ╲
    │      ╲
    │        ╲
    └───────────→ I
    O        I_短
```

| 特征 | 含义 |
|------|------|
| 纵轴截距 | $E$（电动势） |
| 横轴截距 | $I_{\text{短}} = \frac{E}{r}$（短路电流） |
| 斜率绝对值 | $r$（内阻），$r = \left\|\frac{\Delta U}{\Delta I}\right\|$ |

### 7.5 电源的功率与效率

| 项目 | 公式 |
|------|------|
| **总功率** | $P_{\text{总}} = EI$ |
| **输出功率** | $P_{\text{出}} = UI = I^2R = \frac{E^2R}{(R+r)^2}$ |
| **内耗功率** | $P_{\text{内}} = I^2r$ |
| **效率** | $\eta = \frac{P_{\text{出}}}{P_{\text{总}}} = \frac{U}{E} = \frac{R}{R+r}$ |

**输出功率最大的条件：** 当 $R = r$ 时，输出功率最大：

$$P_{\text{出max}} = \frac{E^2}{4r}$$

## 8. 电路分析与简化

### 8.1 等效电阻化简方法

#### 方法一：识别串并联关系

逐步合并明显的串联和并联电阻，直到最终等效为一个电阻。

#### 方法二：等电势法

用不同颜色/编号标记等电势点，重新画电路图，使电路结构清晰。

#### 方法三：电流路径法

从电源正极出发，沿电流方向逐一分析各支路。

### 8.2 电桥电路

```
      ┌────[R₁]────┬────[R₃]────┐
      │            │            │
  ────┤           [G]           ├────
      │            │            │
      └────[R₂]────┴────[R₄]────┘
```

**电桥平衡条件：** $\frac{R_1}{R_2} = \frac{R_3}{R_4}$

- 电桥平衡时，中间桥臂电流为零（G 中无电流），可将桥臂看作断路或短路
- 平衡时等效电阻 = $(R_1+R_3)//(R_2+R_4)$（即上并联下，或左并联右，取决于画法）

### 8.3 电流表与电压表的改装

#### 电流表（表头 G）参数

- **满偏电流 $I_g$：** 表头指针偏转到最大刻度时的电流
- **满偏电压 $U_g = I_g R_g$：** 表头通过满偏电流时两端的电压
- **内阻 $R_g$：** 电流表的内阻

#### 改装为大量程电流表

并联一个分流电阻 $R_s$：

$$R_s = \frac{I_g R_g}{I - I_g}$$

```
  ┌────[G, R_g]────┐
  │                │
  ├────[R_s]───────┤  （并联分流电阻）
  │                │
```

#### 改装为大量程电压表

串联一个分压电阻 $R_f$：

$$R_f = \frac{U}{I_g} - R_g$$

```
  ────[G, R_g]────[R_f]────  （串联分压电阻）
```

### 8.4 滑动变阻器的两种接法

| 连接方式 | 特点 | 适用范围 |
|----------|------|----------|
| **限流式**（串联） | 电路简单，但调节范围有限 | 负载电阻与变阻器总阻值相差不多 |
| **分压式**（并联） | 电压可从0开始调节到E，范围大 | 要求电压从零开始调节；或 $R_{\text{负载}} \gg R_{\text{变阻器}}$ |

> **原则：** 一般情况下优先选用限流式；要求电压从零开始或需要测量多组数据时必须用分压式。

## 9. 电学实验

### 9.1 伏安法测电阻

#### 电流表内接法

```
  ────[A]────[R_x]────
       │              │
       └──────[V]─────┘
```

- **测量值：** $R_{\text{测}} = R_x + R_A > R_x$（偏大）
- **适用条件：** $R_x \gg R_A$（测大电阻）
- **误差来源：** 电流表分压

#### 电流表外接法

```
  ────────[R_x]────────
     │              │
  ──[A]──────┬──────┘
            [V]
             │
```

- **测量值：** $R_{\text{测}} = \frac{R_x R_V}{R_x + R_V} < R_x$（偏小）
- **适用条件：** $R_x \ll R_V$（测小电阻）
- **误差来源：** 电压表分流

#### 内外接法选择

| 判断方式 | 内接法 | 外接法 |
|----------|--------|--------|
| 比较法 | $R_x \gg R_A$ | $R_x \ll R_V$ |
| 临界值法 | $R_x > \sqrt{R_A R_V}$ | $R_x < \sqrt{R_A R_V}$ |
| 试触法 | 接a端→接b端，V示数变化大用内接 | A示数变化大用外接 |

### 9.2 测电源电动势和内阻

#### 实验原理

$$E = U + Ir$$

#### 常用方法

**方法一：伏安法（U-I 法）**

- 测量多组 (U, I) 值
- 作 U-I 图像：纵轴截距 = E，斜率绝对值 = r

**方法二：安阻法（I-R 法）**

$$\frac{1}{I} = \frac{1}{E} \cdot R + \frac{r}{E}$$

- 作 $\frac{1}{I}-R$ 图像：斜率 $= \frac{1}{E}$，截距 $= \frac{r}{E}$

**方法三：伏阻法（U-R 法）**

$$\frac{1}{U} = \frac{r}{E} \cdot \frac{1}{R} + \frac{1}{E}$$

- 作 $\frac{1}{U}-\frac{1}{R}$ 图像：斜率 $= \frac{r}{E}$，截距 $= \frac{1}{E}$

### 9.3 多用电表（万用表）

| 功能 | 原理 |
|------|------|
| 测电压 | 表头串联分压电阻 |
| 测电流 | 表头并联分流电阻 |
| 测电阻 | 闭合电路欧姆定律（自带电源） |

#### 欧姆表原理

$$R_x = \frac{E}{I} - R_{\text{内}}$$

- **欧姆调零：** 两表笔短接，调节使指针指向 0Ω
- **刻度特点：** 左密右疏，不均匀
- **中值电阻：** $R_{\text{中}} = R_{\text{内}} = \frac{E}{I_g}$

## 10. 电容器

### 10.1 基本概念

| 项目 | 内容 |
|------|------|
| **电容** | $C = \frac{Q}{U}$（定义式） |
| **单位** | 法拉（F），1F = 1C/V，常用 μF、pF |
| **物理意义** | 反映电容器容纳电荷本领的大小 |

### 10.2 平行板电容器

$$C = \frac{\varepsilon_r S}{4\pi k d}$$

| 符号 | 含义 |
|------|------|
| $\varepsilon_r$ | 介质的相对介电常数 |
| $S$ | 正对面积 |
| $d$ | 两极板间距 |
| $k$ | 静电力常量 |

- $C \propto S$（正对面积越大，电容越大）
- $C \propto \frac{1}{d}$（极板间距越小，电容越大）
- $C \propto \varepsilon_r$（介质介电常数越大，电容越大）

### 10.3 电容器在电路中的行为

| 状态 | 行为 |
|------|------|
| **稳态直流电路** | 电容器相当于**断路**（所在支路无电流） |
| **充放电过程** | 所在支路有短暂电流，电流方向取决于充/放电 |
| **与电容器串联的电阻** | 稳态时该电阻两端电压为零（无电流通过） |

### 10.4 电容器动态分析（两类问题）

#### 第一类：电容器始终与电源连接（U 不变）

- $d$ ↑ → $C$ ↓ → $Q = CU$ ↓ → $E = \frac{U}{d}$ ↓
- $S$ ↑ → $C$ ↑ → $Q$ ↑ → $E = \frac{U}{d}$ 不变

#### 第二类：电容器充电后断开电源（Q 不变）

- $d$ ↑ → $C$ ↓ → $U = \frac{Q}{C}$ ↑ → $E = \frac{4\pi kQ}{\varepsilon_r S}$ 不变
- $S$ ↑ → $C$ ↑ → $U$ ↓ → $E$ ↓

## 11. 常见题型与解题方法

### 11.1 动态电路分析

**步骤：**

1. 确定变化的电阻（增大还是减小）
2. 判断总电阻的变化
3. 由 $I = \frac{E}{R_{\text{总}} + r}$ 判断总电流变化
4. 由 $U = E - Ir$ 判断路端电压变化
5. 逐步分析各支路和各元件的电压/电流变化

> **口诀：** "串反并同" — 与变化的电阻串联的元件，其电流/电压变化方向与 R 变化方向相反；并联的变化方向相同。

### 11.2 含容电路分析

- 稳态时电容器相当于断路
- 求电容器两端的电压（等于与其并联的电阻两端电压）
- $Q = CU$ 计算电荷量
- 充放电时通过某截面的电量 $\Delta Q = C \cdot \Delta U$

### 11.3 电路故障分析

| 故障类型 | 现象 |
|----------|------|
| **断路**（某处断开） | 断点处电压不为零（等于电源电压）；断点之后无电流 |
| **短路**（两点直接连通） | 短路处电压为零；电流增大 |

### 11.4 非线性电路分析

含有非线性元件（如灯泡、二极管）的电路：
- 方法一：图解法 — 在同一坐标系中画出非线性元件的 I-U 曲线和线性部分的负载线，交点即工作点
- 方法二：假设工作区域，验证

## 12. 公式速查表

### 基本公式

| 公式 | 名称 | 说明 |
|------|------|------|
| $I = \frac{q}{t}$ | 电流定义式 | |
| $I = nqSv$ | 电流微观式 | |
| $U = \frac{W}{q}$ | 电压定义式 | |
| $I = \frac{U}{R}$ | 部分电路欧姆定律 | 仅适用于纯电阻电路 |
| $R = \rho \frac{l}{S}$ | 电阻定律 | 电阻的决定式 |
| $E = I(R + r)$ | 闭合电路欧姆定律 | |
| $U = E - Ir$ | 路端电压 | |

### 串并联公式

| 公式 | 说明 |
|------|------|
| $R_{\text{串}} = R_1 + R_2 + \cdots$ | 串联总电阻 |
| $\frac{1}{R_{\text{并}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$ | 并联总电阻 |
| $R_{\text{并}} = \frac{R_1R_2}{R_1+R_2}$ | 两电阻并联公式 |

### 功率与能量

| 公式 | 适用条件 |
|------|----------|
| $W = UIt$ | 普遍适用 |
| $Q = I^2Rt$ | 普遍适用（焦耳定律） |
| $P = UI$ | 普遍适用 |
| $P = I^2R = \frac{U^2}{R}$ | 仅纯电阻电路 |
| $P_{\text{出}} = \frac{E^2R}{(R+r)^2}$ | 电源输出功率 |

### 电容器

| 公式 | 说明 |
|------|------|
| $C = \frac{Q}{U}$ | 电容定义式 |
| $C = \frac{\varepsilon_r S}{4\pi k d}$ | 平行板电容器决定式 |
| $E = \frac{U}{d}$ | 匀强电场场强与电势差关系 |
