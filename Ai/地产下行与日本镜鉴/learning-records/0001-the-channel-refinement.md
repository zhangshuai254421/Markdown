# 第四问从「卡脖子 vs 被商品化」修正为「谁拥有通向最终付费方的渠道」

第六课给行业分类框架加了第四问：**这一段是「被商品化的」还是别人「绕不开的」？**
依据是日本半导体的对照——日本在同一个产业里丢掉了被商品化的 DRAM（份额约 80% → 实质归零），
守住了绕不开的设备与材料（光刻胶至今约 90%、EUV 掩模检测 >90%、全球设备十强日本占 4 席）。

第七课用制药检验它，**这条问法被打穿了**：

1. **国家层面不成立**。日本制药全球份额 18.7%（1990）→ 4.08%（2024），相对跌幅 **−78%**；
   日本半导体约 50% → 约 9–10%，**−80~82%**。跌得几乎一样惨。
2. **机制也不同**。日本制药企业活下来不是因为专利耐久，是因为
   **药的收入可以搬走、工厂的不行**——武田海外收入 90.9%、安斯泰来 85.3%、第一三共 69%。
3. **而且日本企业不是靠「拥有 IP」拿到份额的，是靠「租用西方渠道」**——
   中外制药 49.5% 的核心营业利润率（日本制药最高）来自把 Hemlibra 出口给罗氏、把 Actemra 授权给罗氏，
   它从没建过全球销售队伍；第一三共的 Enhertu 靠阿斯利康的肿瘤渠道，且是联合商业化而非纯授权。

**修正后的第四问**：**谁拥有通向最终付费方的渠道？**
专利是「制造」的法定垄断，不是「销售」的——它不给你渠道、不给你准入、不给你价格。
三个量化「光有专利值多少钱」的指标：首付款/头条总额 **5.2%**、
里程碑达成率 **22%**（商业化阶段约 5%）、中国对外授权的资产**退货率 40%**。

**最强反证（CXO 反转）**：美国 BIOSECURE 法案瞄准的正是**完全没有专利保护**的 CXO 环节，
结果药明康德美国客户收入占比反而升到约 **68–72%**、净利 **+105.2%**，
因为那里的瓶颈是**装机产能与工艺 know-how**，立法时间表复制不了。
**法律耐久 ≠ 经济耐久，这两个轴几乎正交。**

**对后续课程的含义**：任何关于知识密集型 / IP 密集型行业的判断，
必须跑**渠道测试**而不是**专利测试**。已写进
[行业地图](../reference/industry-map.html) 的第四问与 [MISSION.md](../MISSION.md) 的能力目标。
