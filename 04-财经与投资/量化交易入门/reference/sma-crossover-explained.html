双均线算法详解（SMA 交叉）

第 1 课模拟器里的"双均线 50/200"到底在算什么？这张卡从一根均线讲起，用 3 日/5 日均线手算一次金叉和一次死叉，最后说清它为什么不是一台印钞机。

更新：2026-11-08 · 关联：第 1 课 · 第 3 课 · 术语表 R1

一、一根均线：把噪声抹平

SMA（Simple Moving Average，简单移动平均）就是"最近 N 天收盘价的算术平均"：

SMAN(第 t 天) = (第 t 天收盘价 + 第 t−1 天收盘价 + … + 第 t−N+1 天收盘价) ÷ N

它回答一个问题：最近 N 天，市场平均成本大概是多少？单看某一天的价格会被噪声骗，均线把最近 N 天抹平，趋势的方向就更容易看出来。

天收盘价SMA3 的计算SMA3
110.0数据不足—
212.0数据不足—
311.0(10.0 + 12.0 + 11.0) ÷ 311.00
413.0(12.0 + 11.0 + 13.0) ÷ 312.00
514.0(11.0 + 13.0 + 14.0) ÷ 312.67

注意两件事：① 每来一天新数据，窗口就"往前滑一格"，所以叫移动平均；② 均线永远落后于价格——价格已经涨了，均线要等几天才跟上。这个滞后是后面所有优缺点的根源。

二、两条均线：快线与慢线

把两条不同周期的均线放在一起，就有了"双均线"：

名称第 1 课模拟器性格作用
快线SMA50（50 个交易日 ≈ 2.5 个月）反应快，噪声多捕捉中短期趋势
慢线SMA200（200 个交易日 ≈ 10 个月）反应慢，噪声少代表长期趋势方向

规则只有两句：

状态条件动作
金叉快线从下方穿越到慢线上方买入 / 持仓
死叉快线从上方穿越到慢线下方卖出 / 空仓

关键词是"穿越"（cross），不是"快线高于慢线"本身。快线已经在慢线上方待了三个月，不叫金叉；只有从下往上穿过的那一天，才是新的金叉信号。第 1 课模拟器的代码就是每天比较两条均线的大小，只在"目标仓位变化"时记一次交易。

三、手算一次金叉和一次死叉

50/200 的数字太大，手算不现实。下面用 3 日均线（快线）和 5 日均线（慢线）代替——机制完全一样，只是窗口短、数字小。假设某标的连续 12 天的收盘价如下：

把关键的两天拎出来看：

  • 第 6 天：快线 9.13，慢线 9.24 → 快线还在慢线下方，空仓。
  • 第 7 天：快线 9.67，慢线 9.40 → 快线上穿慢线，金叉，状态从 0 变 1，记一次交易。
  • 第 10 天：快线 10.33，慢线 10.20 → 仍在慢线上方，继续持仓。
  • 第 11 天：快线 9.73，慢线 10.12 → 快线下穿慢线，死叉，状态从 1 变 0，再记一次交易。

别急着说"金叉买入就能赚"。如果按信号当日收盘价成交，这笔交易是第 7 天 10.4 买入、第 11 天 9.2 卖出——亏了约 11.5%，还没算手续费。这已经是偏乐观的当日成交假设；如果按诚实档次日成交，结果会变——可能更好也可能更差，但至少不再是未来函数（第 3 课会专门演示）。这不是例子编坏了，而是双均线的真实性格：它滞后，经常在趋势中后段才确认，等死叉出现时，利润已经回吐甚至倒亏。这就是"震荡市反复打脸"的来源。

换个行情，它也可能刚好吃到一大段趋势。双均线不保证每笔赚钱，它只是把"趋势跟随"写成了无歧义的规则——长期是否正期望，要靠大量样本回测，而不是看一次金叉。

四、对应到第 1 课模拟器的代码

模拟器里真正跑的就是下面几行（backtest-sim.js）：

backtest-sim.js — 双均线的核心逻辑

function sma(arr, n, end) {
  var s = 0;
  for (var i = end - n + 1; i <= end; i++) s += arr[i];
  return s / n;
}

function runSmaCross(px, fast, slow) {
  var pos = [], trades = 0, cur = 0;
  for (var d = 0; d < px.length; d++) {
    if (d < slow - 1) { pos.push(0); continue; }   // 慢线还没攒够数据
    var want = sma(px, fast, d) > sma(px, slow, d) ? 1 : 0;
    if (want !== cur) { trades++; cur = want; }    // 目标仓位变化 = 一次交易
    pos.push(cur);
  }
  return { pos: pos, trades: trades };
}

逐行翻译成人话：

  • sma(px, 50, d)：从第 d 天往前数 50 个收盘价，求平均。
  • want = 快线 > 慢线 ? 1 : 0：目标仓位只有两个状态——持仓（1）或空仓（0）。
  • want !== cur：只有"目标"和"当前"不同时才动作，并记一次交易。每天比较均线不算交易，仓位变化才算。
  • d < slow - 1：慢线需要 200 天才有值，所以前 199 天强制空仓；模拟器的 warmup: 200 再把这段暖机期从对比窗口里切掉。

模拟器还有一层"信号执行延迟"：delay = 1 表示第 d 天产生的信号，第 d+1 天才生效（诚实档）；delay = 0 表示当天收盘信号当天成交（作弊档，用了未来信息）。第 3 课会专门让你对比这两档。

最后，equityOf 里每次仓位变化扣一次 costPerSide——所以交易次数越多，成本扣得越多。这就是第 1 课的全部重点：双均线的利润 = 信号优势 − 换手成本。

五、为什么是 50/200？为什么它不是"好策略"？

  • 50/200 只是惯例，不是魔法数字。50 个交易日约 2.5 个月，200 个约 10 个月；一个偏中短期，一个偏长期。换成 20/60 或 5/20，结果会变——但"哪个参数好就留哪个"正是第 4 课要抓的过拟合。
  • 滞后。慢线要 200 天才能算出来，趋势走了一大段它才转头。金叉时价格往往已经不便宜，死叉时往往已经跌了不少。
  • 震荡市假信号。价格横盘时，快线会反复上穿下穿慢线，每次都是一次买卖、一次成本。趋势策略在震荡市"反复打脸"，说的就是这个。
  • 成本敏感。一次金叉买入 + 一次死叉卖出 = 一个往返。按单边 0.3% 算，一个往返约 0.6%；十次往返就是 6% 的拖累。第 1 课模拟器让你把成本从 0 调到 0.3%，就是让你亲眼看到这笔税。
  • 它更适合当"趋势过滤器"。实务里常把双均线和其他规则组合：均线只决定"允不允许做多"，具体买什么、买多少、何时止损，另有规则。把它单独当印钞机，就是把它当成了它不是的东西。

六、自测（先答，再看答案）

① 收盘价为 10、12、14，SMA3 是多少？② 金叉和死叉的定义各是什么？③ 为什么双均线要等 200 个交易日才能真正开始？④ 为什么成本对双均线伤害大，对买入持有却几乎没影响？

① (10+12+14)÷3 = 12。② 金叉：快线从下方穿越慢线；死叉：快线从上方穿越慢线。③ SMA200 需要 200 个收盘价才能算出第一个值；在此之前快慢关系未定义，所以模拟器把这段暖机期排除（warmup）。④ 双均线每次交叉都买卖一次，成本按交易次数累积；买入持有只交易一次，成本只扣一次。
