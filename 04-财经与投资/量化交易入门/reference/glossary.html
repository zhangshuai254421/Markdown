一、绩效指标（衡量一个策略好不好）

术语英文一句话定义常见坑
净值曲线Equity Curve策略资金随时间变化的曲线，是回测的核心输出。只看终点不看路径，会漏掉中途的深回撤。
总收益率Total Return期末净值 ÷ 期初净值 − 1。不告诉你花了多少年，也没说冒了多大风险。
年化收益CAGR把总收益折算成"每年复利多少"的几何平均增长率。回测期太短（<3 年）时，CAGR 基本是噪声。
最大回撤Max Drawdown净值曲线从历史最高点跌到最低点的最大幅度。它只记录最惨的一段，不代表"平均有多惨"。
基准Benchmark用来对照的策略/指数（A股常用沪深300）。跑不赢基准的复杂策略没有存在意义。选一个弱的基准来"证明"策略有效——隐形作弊。
胜率Win Rate盈利交易次数 ÷ 总交易次数。高胜率 × 小赚、低胜率 × 大赔，照样亏——必须配盈亏比看。
盈亏比Profit/Loss Ratio平均每笔盈利 ÷ 平均每笔亏损。单看胜率或单看盈亏比都没有意义。
期望值Expected Value胜率×平均盈利 − 败率×平均亏损；长期盈利的唯一来源。期望值为正但样本太少时，实盘可能长期不兑现。
夏普比率Sharpe Ratio(收益 − 无风险利率) ÷ 收益波动率：每承担一份波动换来多少回报。用日收益算的夏普会低估肥尾风险；第 6 课展开。

二、回测方法论（怎么验证一个策略）

术语英文一句话定义常见坑
回测Backtest把策略规则放进历史数据里模拟执行，检验它过去会怎样。回测好 ≠ 未来好；它只回答"过去是否成立"。
信号Signal策略产生的买/卖/空仓指令，由明确规则算出。规则含糊（"涨得多就卖"）的信号无法回测。
SMASimple Moving Average最近 N 个周期收盘价的算术平均，用来平滑价格噪声。均线滞后于价格；窗口越长越平滑，也越慢。
双均线SMA Crossover快线（如 SMA50）与慢线（如 SMA200）比较：快线上穿慢线买入，下穿卖出。详见 R5。震荡市假信号多；参数是自由度，容易过拟合。
金叉 / 死叉Golden / Death Cross快线从下往上穿越慢线 = 金叉；从上往下 = 死叉。是事后确认信号，不是预测；金叉不代表一定上涨。
样本内 / 样本外In / Out-of-Sample调参数用的数据段 vs 从未参与调参的验证数据段。反复"偷看"样本外调参，它就变成了样本内。
过拟合Overfitting参数调得完美贴合历史噪声，未来立刻失效。参数越多、回测越漂亮，越该怀疑过拟合。
未来函数Look-ahead Bias用了当时不可能知道的数据做决策（如用收盘价在盘中成交）。最常见的回测作弊，回测利润虚高的头号来源。
幸存者偏差Survivorship Bias股票池里只留了活到今天的股票（退市/暴雷的消失）。用"今天的沪深300成分股"回测20年就是典型。
走查验证Walk-forward滚动窗口：用过去调参→用紧接着的未来验证，模拟真实使用。计算量大，但比一次性样本内外划分更接近实战。

三、A股市场机制（策略必须服从的物理定律）

术语英文一句话定义对策略的含义
T+1T+1 Settlement今天买的股票，明天才能卖。日内反转策略在股票上不可行；尾盘买入成为主流执行方式。
涨跌停Price Limit主板单日涨跌幅限制 ±10%（ST ±5%，创业板/科创板 ±20%）。涨停买不进、跌停卖不出——回测必须处理"想交易但成交不了"。
印花税Stamp Duty卖出股票时国家收取的税（2023年8月起为成交额的 0.05%，单边卖出）；ETF 免征。不可谈判的成本；高换手策略的天然敌人。用 ETF 回测时把印花税设为 0。
做空受限Short Constraints普通个人账户基本不能做空个股（融券门槛高、券源少）。A股策略基本只有"做多/空仓"两个状态，与美股两极反转策略根本不同。

四、交易执行（成本从哪里来）

术语英文一句话定义常见坑
佣金Commission券商每笔交易收的手续费，万2.5~万3 常见，常有最低 5 元限制。小资金高频交易被"最低5元"隐性重税。
滑点Slippage信号价与实际成交价之差。回测用收盘价成交 = 零滑点 = 自欺；小盘股滑点远大于大盘股。
换手率Turnover一段时间内买卖总额占资金的比例；换手越猛成本越高。成本敏感度测试：把费率调高 3 倍重跑，利润还在才是真利润。
仓位Position Sizing每笔交易投入多少资金的决定。决定生死的往往不是选股而是仓位；与《炒股的智慧》资金管理同源。

五、掘金量化 C# SDK 术语（课程主平台）

术语一句话定义常见坑
Strategy掘金的策略基类；你的策略继承它，重写 OnInit/OnBar 等方法。把策略写成普通类、忘了继承 GMSDK.Strategy，引擎永远不会调用它。
OnInit回测/实盘开始前调用一次；在这里订阅行情、初始化状态。把下单逻辑写进 OnInit——它只跑一次，不会按 K 线重复。
OnBar每来一根 K 线调用一次（日线即每个交易日一次）。以为它只在收盘调用；不同频率下 bar 的周期不同。
Subscribe订阅标的与频率，如 Subscribe("SHSE.510300", "1d")。标的代码格式写错（应为 SHSE.600000 / SZSE.000001），或忘了订阅导致 OnBar 不触发。
OrderTargetPercent把仓位调整到占总资产的目标比例；0.95 = 95%，0 = 清仓。用 1.0 满仓时手续费会让资金不足——留 5% 现金。
SetBacktestConfig设置回测起止、初始资金、佣金、滑点、复权；必须在 Run() 前调用。默认佣金/滑点是 0，不设就是"零成本"假报告。
OnBacktestFinished回测结束回调，参数 Indicator 含 pnlRatio、sharpRatio、maxDrawdown 等指标。字段名拼错（是 sharpRatio 不是 sharpeRatio）。
token / 策略 IDtoken 在终端"系统设置 → 密钥管理"；策略 ID 在"量化研究 → 新建策略 → C#"时生成。把 token 提交进 Git 仓库——它等同账号钥匙。

六、数据口径（复权与价格）

术语一句话定义常见坑
不复权交易所原始成交价，不做任何分红/拆分调整。分红除息日价格会"跳空"；跨分红比较会低估真实收益。
前复权以某个基准日为锚，把历史价格向下调整到与基准日可比。基准日不同，同一天价格不同；每次分红后会重算，数据是"时变"的。
后复权以历史某日为锚，把之后的价格向上调整，累计真实收益。适合算长期收益，不适合看盘/挂单。
定点复权前复权的一种：基准日固定为指定日期（如回测结束日）。掘金回测 ADJUST_PREV 用它；改回测结束日，整段历史价格会变。
复权因子把原始价换算成复权价的乘数；分红/拆分后更新。不同数据商的因子/算法不同，同一天可能差几分钱。

510300 的试金石：2024-12-31 不复权收盘 4.022；AKShare qfq（2026-11 下载）3.811（差 0.211 = 2025-06-18 的 0.088 + 2026-01-19 的 0.123）。详见 R6。

本表的元规则：每当你想评价一个策略"好不好"，禁止只报总收益率。完整句式 = 年化收益 + 最大回撤 + 交易成本假设 + 与基准的对比。这是本课程从头到尾的纪律。
