掘金量化 C# SDK 速查

课程主平台是掘金量化（MyQuant，myquant.cn）。这张卡把第 2-3 课用到的 API 压缩成一页，方便你写策略时对照。API 细节以官方文档为准：C# SDK 快速开始 · 策略基类。

一、策略骨架

MyStrategy.cs — 最小可运行结构

using GMSDK;

public class MyStrategy : Strategy
{
    private const string Symbol = "SHSE.510300"; // 沪市 ETF；深市写 SZSE.000001

    public MyStrategy(string token, string strategyId, StrategyMode mode)
        : base(token, strategyId, mode) { }

    public override void OnInit()
    {
        Subscribe(Symbol, "1d");                 // 订阅日线；也可 "60s"、"tick"
    }

    public override void OnBar(Bar bar)
    {
        // 你的信号逻辑：读 bar.close，决定买/卖/不动
    }

    public override void OnBacktestFinished(Indicator indicator)
    {
        // 回测结束：indicator.pnlRatio / sharpRatio / maxDrawdown ...
    }
}

Program.cs — 回测入口

using System;
using GMSDK;

class Program
{
    static void Main()
    {
        string token = "你的 token";        // 终端：头像 → 系统设置 → 密钥管理
        string strategyId = "你的策略 ID";  // 终端：量化研究 → 新建策略 → C#

        var s = new MyStrategy(token, strategyId, StrategyMode.MODE_BACKTEST);

        // 起止时间、初始资金、成交比例、佣金、滑点、复权
        s.SetBacktestConfig("2016-01-01 09:30:00", "2025-12-31 15:00:00",
                            100000, 1, 0.0003, 0.001, Adjust.ADJUST_PREV);

        int code = s.Run();                  // 0 = 成功；阻塞到回测结束
        Console.WriteLine("返回码: " + code);
    }
}

二、生命周期：引擎什么时候调用你

回调时机典型用途
OnInit()开始前一次订阅行情、初始化状态、设定时任务
OnBar(Bar bar)每根 K 线一次算信号、决定下单
OnOrderStatus(Order order)委托状态变化时确认成交/拒单，再改仓位状态
OnBacktestFinished(Indicator indicator)回测结束一次打印/保存绩效指标

记录成交明细：重写 OnOrderStatus(Order order)，当 order.status == (int)OrderStatus.OrderStatus_Filled 时读 order.filledVwap（成交均价）、order.filledVolume（已成量）、order.filledAmount（成交金额）、order.filledCommission（手续费）。注意 status/side 字段是 int，比较时要强转，例如 order.side == (int)OrderSide.OrderSide_Buy。

三、常用 API

API作用注意
Subscribe(symbol, "1d")订阅标的与频率标的格式 SHSE.600000 / SZSE.000001
OrderTargetPercent(symbol, percent, PositionSide.PositionSide_Long, OrderType.OrderType_Market)调仓到目标持仓比例0.95=95%，0=清仓；100% 易因手续费拒单
OrderPercent(symbol, percent, side, orderType, positionEffect)按总资产比例下单买入用 OrderSide_Buy + PositionEffect_Open
OrderVolume(symbol, volume, side, orderType, positionEffect, price)按股数下单股票 100 股整数倍，不足向下取整
GetOrder(orderId)查委托状态下单成功 ≠ 成交；以 OnOrderStatus 为准
Now()当前回测/实盘时间回测里别用 DateTime.Now，那是真实时间
Stop()停止策略实盘退出时用

四、终端操作路径

  1. 下载安装：myquant.cn/terminal（Windows 终端）。
  2. 新建策略：量化研究 → 新建策略 → 选 C# → 记下策略 ID。
  3. 拿 token：头像 → 系统设置 → 密钥管理 → 复制。
  4. 写代码：用 Visual Studio 打开终端生成的 .sln。
  5. 跑回测：按 F5；终端保持登录，结束后到 策略研究 → 绩效 看报告。

五、常见坑（先看这一节）

  • 佣金/滑点默认 0：SetBacktestConfig 不显式设置，报告就是"零成本"假象。
  • 100% 仓位被拒：手续费会让现金不足；用 95% 留缓冲。
  • 标的代码格式：SHSE.（沪）/ SZSE.（深），不是 600000.SH。
  • x86/x64 位数：SDK 版本与项目平台目标不一致会报 BadImageFormatException。
  • token 泄露：token 等同账号钥匙，别提交进 Git。
  • 撮合模式：选"下一根 K 线开盘"才是诚实档；"当前 K 线收盘"等于自己开作弊器。

六、回测报告字段（Indicator）

字段含义
pnlRatio累计收益率
pnlRatioAnnual年化收益率
sharpRatio夏普比率（注意拼写是 sharp，不是 sharpe）
maxDrawdown最大回撤
winRatio胜率
openCount / closeCount开仓/平仓次数
riskRatio / calmarRatio风险比率 / 卡玛比率

有疑问随时问老师。API 版本差异、字段名对不上、终端报错——把错误码和代码贴过来，我们一起查。
