国内量化平台地图（中文生态）

你的问题："国内有啥量化模型？国外全是英文，学习成本太高。"先校准两个词：你说的"数据掘金"，正式名称是掘金量化（MyQuant，myquant.cn）；你真正要找的是中文生态的量化平台。现成的"模型"（别人卖给你的策略）是另一个话题——文末有专门警告。这张地图的结论先给你：国内生态不仅成熟，而且你的 C# 路线在其中有一条全中文的通道。

C# 在国内生态的位置

这张地图里最重要的一个事实：掘金量化是本课程覆盖的平台里，唯一把 C# 当一等公民的主流平台——官方支持中心（myquant.cn/docs2）有专门的 C# SDK 板块，产品页明确列出 Python / C++ / C# / Matlab 四种语言的策略 SDK，文档、社区（掘金社区）、回测、仿真、实盘全链路中文。其他平台清一色 Python 优先。

所以你担心的"英文成本"，现在已经被课程本身消除：第 2-3 课已经在掘金量化的 C# SDK 里完成，从安装终端、拿 token、写 OnInit/OnBar 到读绩效报告，全中文。事件循环、五要素、作弊识别这些心智模型，也已经在中文文档和 A 股数据上长出来了。

路线不变，三步走：① 学习期 = 掘金 C# SDK（第 2-3、6 课）+ 自建 C# 引擎与 AKShare 数据（第 5、7-8 课）；② 模拟盘 = 掘金终端仿真（全中文，C# SDK）；③ 实盘 = 掘金实盘，或与 QMT/PTrade 比价后再定。没有任何一步被迫离开中文。

警告：如果你说的"模型"是别人卖给你的现成策略

国内卖"量化模型/策略/信号"的市场鱼龙混杂，而审查它们的工具你已经全有了——任何人在卖你策略，先问三件事（R2）：① 回测报告过三关了吗（五宗罪检验 + 稳健性测试）？② 第 8 课的三个物理问题答得出吗（空头腿怎么建？T+1 怎么绕？涨跌停怎么成交）？③ 样本外只碰过一次的记录在哪？三问答不出，就是第 8 课说过的"两头吃"话术——回测漂亮是因为它有五宗罪里的至少一宗。

健康的替代品：聚宽社区的经典策略库（社区干货索引）和掘金社区（资源合集）里有大量公开、免费、可读源码的策略——拿它们练第 10 课的归因（"这个策略暴露的是动量还是反转？"），比买任何"模型"都有价值。

英文成本的诚实账

哪些必须英文，哪些全程中文，算清楚就不焦虑了：

  • 全程中文（课程主路径）：第 2-3 课掘金 C# SDK；读书路线（《打开量化投资的黑箱》《量化交易：自己动手做算法交易》《因子投资：方法与实践》都是中译/中文原著）；数据源文档；集思录、掘金、聚宽社区；QMT/PTrade 资料。
  • 已移除：第 2-3 课原先的 QuantConnect/LEAN 文档——2026-11-06 平台迁移后不再需要。
  • 可选英文（不是课程要求）：读海外开源引擎源码、读因子前沿的学术论文。想走更深时再碰；你第 7 课自建引擎的习惯，本来就是用读源码代替读论文。

行动三步（每步 30 分钟）

  1. 装掘金终端：myquant.cn 下载终端 → "量化研究 → SDK 下载" 选 C# → 跑通一个官方示例策略。对照作业：找出它的事件模型与第 7 课你引擎的同构点（OnInit 对应初始化？每根 K 线对应 OnBar？）。
  2. 读两个公开策略：聚宽社区或掘金社区各挑一个经典策略（轮动、海龟、双均线任选），用第 10 课的语言写一句归因——"它暴露的是____因子，A 股物理对它的____有影响"。
  3. 门槛调查（可留到模拟盘后）：给你开户的券商客服问一句"QMT/PTrade/掘金实盘的开通条件"——把答案记进你的第 12 课模拟盘日记。
