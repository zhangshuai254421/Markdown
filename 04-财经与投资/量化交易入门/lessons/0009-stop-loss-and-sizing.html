止损与仓位：错了会伤多深

策略回答"什么时候进出"，仓位回答"错了会伤多深"——后者才是活下来的那一半。本课把止损写成你熟悉的状态机出边，再用两条公式（2% 规则、凯利公式）把"该买多少"从拍脑袋变成算术。

止损：状态机的一条出边

把持仓看作三状态状态机：空仓 →（金叉买入）→ 持有 →（死叉卖出 或 止损）→ 空仓。止损就是从"持有"出发的一条无条件出边：价格跌破买入价 ×(1−8%)，立刻卖出，不讨论。

为什么必须机械：《炒股的智慧》反复强调，亏损中的交易者不值得信任——侥幸心理在浮亏 8% 时达到峰值，恰好是最该离场的时刻。机械止损的意义不是"8% 是 magic number"，而是把纪律从事后意志力搬进事前规则。这正是量化对你的吸引力所在：你擅长让规则替你扛住情绪。

A 股物理会咬你的止损一口：T+1 意味着今天买入、明天跳空跌停开盘，你的 8% 止损实际以 −10% 甚至更低成交。止损设定 ≠ 最大亏损，引擎必须如实模拟这一点（下面的代码已经按开盘价成交）。

Program.cs — 在第 8 课事件循环开头、信号判断之前插入

const double StopPct = 0.08;              // 止损线：跌破买入价 8%
double entryPrice = 0;                    // 买入时记录（买入分支里 entryPrice = fill;）

// 止损出边：先于策略信号执行，T+1 约束照常生效
if (shares > 0 && today.Date > lastBuyDay && today.Open < entryPrice * (1 - StopPct))
{
    double fill = today.Open;             // 跳空开盘只能按开盘价出
    cash += shares * fill
          - Math.Max(shares * fill * Commission, MinFee)
          - shares * fill * StampTax;
    shares = 0;
    prevSignal = 0;                       // 状态机回到空仓
}

2% 规则：仓位由止损距离反推

经典公式（Van Tharp 的仓位管理思想）：仓位 = 单笔可承受亏损 ÷ 止损距离。

仓位 = (本金 × 2%) ÷ 止损距离

要素取值（例）
本金100,000 元
单笔最大可亏（2%）2,000 元
止损距离5%
仓位 = 2000 ÷ 0.0540,000 元（四成仓）

注意方向：止损越近，仓位越大；止损越远，仓位越小——总风险被锁死在 2%，仓位只是它的影子。所以"止损 5% 买四成仓"不是胆量问题，是除法。

凯利公式：增长与爆仓之间的最优解

2% 规则是"防守端"的答案。进攻端的经典答案是凯利公式（Ed Thorp 把它带进股市，见 Wikipedia: Kelly criterion）：

K = W − (1−W)/R　（W=胜率，R=盈亏比：平均盈利÷平均亏损）

手算一遍：胜率 40%、盈亏比 2（赚时平均赚 2 份、亏时平均亏 1 份——趋势策略的典型画像）：K = 0.4 − 0.6/2 = 0.1，即 10% 仓位。

为什么实践里用半凯利（K/2）：增长率在最优解附近是平的——半仓凯利牺牲极少的长期增长，波动却减半；而你的 W、R 是估计值，实盘里 W 被高估是常态，半凯利是"对估计误差的保险"。Thorp 本人在实战中长期使用分数凯利。

一条自查反射：算出你的半凯利（比如 5%）。若当前某笔仓位的风险敞口连 1/4 凯利都超过——你在下重注，不论感觉多好。把它加进 R2 第三关的自查：仓位是否 ≤ 半凯利？

凯利的前提是你知道 W 和 R——而它们只能从回测估计。回测里 W=45%，实盘可能只有 35%。这就是凯利公式给出"数学最优"、实战却永远打折的原因：最优解建立在你最不确定的参数上。

动手（约 30 分钟）：

  1. 给引擎装上 8% 止损，重跑双均线，对比安装前后：最大回撤变了多少？年化牺牲了多少？（这就是"止损的保险费"）
  2. 手算：本金 10 万、止损距离 4%，2% 规则给多少仓位？再算 W=0.45、R=1.5 的凯利与半凯利。
  3. 记录你策略回测里的 W 和 R（交易笔数够多才有意义；第 3 课说过趋势策略十年只有十几笔——样本太小，这本身就是答案的一部分）。
