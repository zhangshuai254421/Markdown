自建 C# 回测引擎（上）：核心循环

掘金是别人的引擎。本课开始你拥有自己的：一个约 60 行的最小可行回测引擎。目标不是替代掘金，而是打开黑箱——第 8 课要建模的 A 股物理定律（T+1、涨跌停、印花税），掘金已经替你实现，但只有自己写一遍，你才有能力读懂并质疑它的报告。

为什么值得自建

  1. 懂内部：成交、持仓、净值如何产生，你将一行行亲眼看见——以后读任何平台报告都不再神秘。
  2. A 股物理：T+1、涨跌停不能成交、印花税单边——掘金已经实现，但对你是不透明的；自己写一遍，才能验证平台报告、做定制规则。
  3. 不被黑箱绑架：作者观点用黑箱引擎做关键决策，等于让不明代码替你签合同。

引擎的骨架

   CSV数据 ──> DataReader ──> [ 事件循环: 逐根K线 ] ──> 统计输出
                                │
              ┌─────────────────┼─────────────────┐
              v                 v                 v
           Strategy          Broker          Portfolio
          (产生信号)      (按规则撮合)     (现金/持仓/净值)

事件循环一次迭代 = 一根 K 线走完全流程：喂新价格 → 更新持仓市值 → 接收策略信号 → 撮合成交 → 记账。这个结构与掘金的 OnBar 完全同构——你已经会用它，只是那时引擎藏在平台后面。

最小可行引擎

新建 .NET 控制台项目（dotnet new console），把第 5 课的 CSV 复制进项目。完整代码如下——注意诚实执行的实现位置：信号基于 昨收，成交在今开（时刻上晚于信号，杜绝未来函数）：

Program.cs — 双均线 50/200，信号次日开盘成交

using System.Globalization;
using System.Text;

// ---------- 数据 ----------
var lines = File.ReadAllLines("hs300etf_daily.csv").Skip(1);
var bars = lines
    .Select(l => l.Split(','))
    .Select(f => new Bar(
        Date:  DateTime.Parse(f[0], CultureInfo.InvariantCulture),
        Open:  Parse(f[1]), Close: Parse(f[2]),
        High:  Parse(f[3]), Low:   Parse(f[4])))
    .OrderBy(b => b.Date)
    .ToList();

static double Parse(string s) => double.Parse(s, CultureInfo.InvariantCulture);

// ---------- 策略：SMA50/200，输出每日目标仓位 ----------
static int Signal(IReadOnlyList<Bar> bars, int i)     // 用截至昨收的数据
{
    if (i < 200) return 0;
    double smaFast(int end, int n) { double s = 0; for (int k = end - n; k < end; k++) s += bars[k].Close; return s / n; }
    return smaFast(i, 50) > smaFast(i, 200) ? 1 : 0;   // i 指向"昨天"，不含今
}

// ---------- Broker + Portfolio ----------
double cash = 100_000, shares = 0;
const double FeeRate = 0.00025;                        // 佣金万2.5（A股无强制单边税差在此简化）
var equity = new List<double>();
int prevSignal = 0;

// ---------- 事件循环 ----------
for (int t = 200; t < bars.Count; t++)
{
    int signal = Signal(bars, t);                      // 昨收算出的信号
    var today = bars[t];

    if (signal != prevSignal)                          // 状态翻转 → 今日开盘成交
    {
        double fill = today.Open;                      // 今开成交：晚于信号时点
        if (signal == 1 && shares == 0)
        {   shares = Math.Floor(cash * (1 - FeeRate) / fill); cash -= shares * fill * (1 + FeeRate); }
        else if (signal == 0 && shares > 0)
        {   cash += shares * fill * (1 - FeeRate); shares = 0; }
        prevSignal = signal;
    }
    equity.Add(cash + shares * today.Close);           // 每日收盘记净值
}

// ---------- 统计 ----------
double total = equity[^1] / equity[0] - 1;
double years = (bars.Count - 200) / 252.0;
double cagr = Math.Pow(equity[^1] / equity[0], 1 / years) - 1;
double peak = 0, maxdd = 0;
foreach (var v in equity) { peak = Math.Max(peak, v); maxdd = Math.Max(maxdd, 1 - v / peak); }

Console.OutputEncoding = Encoding.UTF8;
Console.WriteLine($"总收益 {total:P1} | 年化 {cagr:P1} | 最大回撤 {maxdd:P1}");
Console.WriteLine($"区间 {bars[200].Date:yyyy-MM} ~ {bars[^1].Date:yyyy-MM}，共 {bars.Count - 200} 个交易日");

record Bar(DateTime Date, double Open, double High, double Low, double Close);

列序是这里最容易踩的坑：AKShare 的 ETF 日线列序是 日期, 开盘, 收盘, 最高, 最低, …——收盘在最高/最低前面，不是常见的 OHLC 顺序。上面的映射已按这个顺序写好；如果你换成股票接口或其他数据源，先 Console.WriteLine(lines.First()) 核对表头再改列号。把收盘价读成最低价，回测会给你一份完全不同的成绩单。参考掘金 C# 策略里的 OnBar 回调就是同一个骨架——你第 2-3 课写的策略，本质上也是"引擎喂一根 K 线、策略回一个动作"。

和掘金的结果对不上？先看 R6 · 回测数据对不上排查清单——"定点前复权 vs 最新日前复权"和 AKShare 列序是前两个必查项。

对账时先比交易清单：在引擎里用 List<Trade> 记录每笔的“信号日 / 成交日 / 方向 / 成交价 / 数量 / 费用”，再和平台的成交记录逐笔对照——比只看总收益更快定位问题。

TDD：先手算，再让引擎通过

你在 TddLab 练的红绿循环在这里原样适用——引擎是沉默的骗子，bug 不会抛异常，只会给你一个貌似合理的净值。所以先写一个 3 根 K 线的手算用例：

动手（约 40 分钟）：

  1. 跑通引擎，记下总收益/年化/回撤。
  2. 交叉验证：把同一份数据、同一区间喂给第 3 课的掘金双均线（510300），两边数量级应一致。先过 R6 对账清单：掘金回测的 ADJUST_PREV 是以回测结束日为基准的定点前复权，AKShare qfq 是以最新日为基准——同一天价格不同是正常的；先比不复权或归一化净值，再把佣金/滑点调成一致。
  3. 手算用例：构造 3 根假 K 线（开盘=收盘），手算期望净值与交易笔数，写成一个单元测试让引擎通过——测试不过就是引擎有 bug 或你手算错了，两者都要查。
  4. 思考题：把 Signal(bars, t) 里的 i < end 范围改成包含 t（今天），会发生什么？——你刚刚造出了第 3 课模拟器里的"作弊档"，在 C# 里再认识它一遍。

本课的诚实边界：本引擎刻意简化了 A 股的多数物理规则（涨跌停、T+1、印花税单边、最低佣金 5 元都没建模）。它现在是"简化物理"——按 T+0、可做空、无涨跌停撮合（这套规则更像美股，课上戏称"美股物理"）。第 8 课逐条装上 A 股定律，再拿掘金的报告做对照。
