自建 C# 回测引擎（下）：A 股物理定律

第 7 课的引擎跑在"简化物理"里（T+0、可做空、无涨跌停——更像美股，课上简称"美股物理"）。今天把四条 A 股定律逐条写进代码：T+1、涨跌停、印花税单边、禁止做空。最后看一个重要事实：同一份策略思想，在美股成立，在 A 股可能根本无法表达——策略空间是由市场物理决定的。

说明：掘金的回测已经内置这些 A 股规则。本课不是"平台做不到所以自己写"，而是"自己写一遍，才能真正读懂平台的报告"——这和第 7 课的动机一致。

四条定律总览

定律现实引擎建模若忽略会怎样
T+1当日买入，次日才能卖出记录买入日，canSell = 今天 > 买入日日内止损失效，隔夜风险被系统性低估
涨跌停主板 ±10%（创业板/科创板 ±20%）开盘涨停禁买入、开盘跌停禁卖出（保守处理）假成交：你以为止损卖出了，现实中你在卖方长队里
成本结构佣金约万2.5（最低5元）；印花税万5、仅股票卖出方（2023 年 8 月起）；ETF 免征双边佣金 + 单边印花税（股票）成本低估，长周期回测收益虚高
禁止做空融券 2024 年起监管连续收紧，实际近乎停摆持仓只有 0/1 两状态，禁止负持仓多空策略的空头腿凭空赚到不存在的钱

费率以多数券商零售档为参考，你的实际佣金以开户合同为准；过户费等零头项本课刻意不计（第 7 课的简化原则继续生效）。

逐条写进引擎

在引擎头部加常量，然后替换事件循环里成交判断的那一段：

Program.cs — A 股物理版（在第 7 课基础上修改）

// ---------- A股物理常数 ----------
const double Commission = 0.00025;   // 佣金 万2.5
const double MinFee     = 5;         // 佣金最低 5 元
const double StampTax   = 0;         // 510300 是 ETF，免征印花税；个股改为 0.0005
const double LimitPct   = 0.10;      // 涨跌停 ±10%（主板/多数ETF）

DateTime lastBuyDay = default;

for (int t = 200; t < bars.Count; t++)
{
    int signal = Signal(bars, t);
    var today = bars[t];
    var prevClose = t > 0 ? bars[t - 1].Close : today.Open;

    bool limitUp   = today.Open >= prevClose * (1 + LimitPct - 0.0005);
    bool limitDown = today.Open <= prevClose * (1 - LimitPct + 0.0005);
    bool canSell   = shares > 0 && today.Date > lastBuyDay;      // T+1

    if (signal != prevSignal)
    {
        bool traded = false;

        if (signal == 1 && shares == 0 && !limitUp)              // 涨停买单作废
        {
            double fill = today.Open;
            shares = Math.Floor(cash * (1 - Commission) / fill);
            cash -= shares * fill + Math.Max(shares * fill * Commission, MinFee);
            lastBuyDay = today.Date;
            traded = true;
        }
        else if (signal == 0 && canSell && !limitDown)           // 跌停卖单作废
        {
            double fill = today.Open;
            cash += shares * fill - Math.Max(shares * fill * Commission, MinFee)
                                  - shares * fill * StampTax;    // 印花税单边
            shares = 0;
            traded = true;
        }

        if (traded) prevSignal = signal;   // 只有成交才更新；被挡下则次日重试
    }
    equity.Add(cash + shares * today.Close);
}

ETF 特别注意：印花税只对股票卖出征收，510300 这类 ETF 免征。上面的代码默认 StampTax = 0，就是按 510300 的规则写的；如果你把它改成 0.0005 又用 ETF 跑，会凭空多扣 0.05%/次——这正是"加完四定律反而少 0.4 个点"的常见来源。想看印花税的真实影响，把标的换成个股（如 SHSE.600000）并把 StampTax 设回 0.0005。

为什么 510300 的四定律前后差别很小？因为大多数定律"不绑定"：T+1 只在同日买卖时生效（50/200 很少同日反向）；涨跌停要求单日 ±10%（510300 极少触及）；禁止做空对只做多策略无影响；印花税对 ETF 本来就是 0。四定律不是"每条都要扣分"，而是"哪条会咬你，取决于策略和品种"——高频/日内/做空策略才会被它们重创。

定律510300 日线双均线高频 / 日内个股多空
T+1很少绑定（很少同日反向）强绑定强绑定
涨跌停很少绑定（极少 ±10%）强绑定强绑定
印花税0（ETF 免征）强绑定强绑定（卖出 0.05%）
禁止做空无影响（只做多）无影响强绑定（空头腿消失）

为什么"开盘涨停禁买、开盘跌停禁卖"是保守且接近现实的方向：涨停时买方在长队里排队，你的买单大概率轮不到；跌停时卖方在长队里排队，你的卖单同样大概率轮不到。反过来（涨停卖出、跌停买入）成交是容易的。引擎按"轮不到"处理，就是把现实里最不利的情形计入回测——宁可回测难看，不可实盘意外。

案例：美股成立，A 股失效

学术文献里的经典策略"短期反转多空"：买入近期跌幅最大的股票、同时做空涨幅最大的股票（美股长期回测为正收益，Jegadeesh 1990 年代起有系列研究）。把它搬到 A 股会发生什么？

策略部件美股A 股个人
买入近期大跌股✓✓（跌停买入反而容易成交）
做空近期大涨股✓（融券便利）✗ 融券近乎停摆，空头腿消失
当日止损离场✓✗ T+1，隔夜跳空无法回避

结论不是"A 股没有策略可做"，而是：A 股个人的策略空间 = 只做多 + 空仓两状态 + 日线以上周期。引擎里的 0/1 两状态不是缺陷，是对物理的忠实。第 3 课的双均线恰好是"多/平"两态——它能在 A 股表达；第 10 课你会给这些"可表达的策略"一个学术分类。

小心"两头吃"的话术：任何在 A 股实盘宣传"多空对冲、日内高频"的个人策略，先问三个物理问题——空头腿怎么建？T+1 怎么绕？涨跌停怎么成交？答不出即视为虚假宣传（对照 R2 第三关）。

动手（约 30 分钟）：

  1. 把四条定律装进第 7 课引擎，重跑双均线，对比三个数字（总收益/年化/回撤）与"简化物理版"的差异；再拿掘金的 510300 回测报告对照——你的规则实现和平台结果差在哪？用 510300 时 StampTax 保持 0；想测试印花税，换个股并把 StampTax 设为 0.0005。如果还要和同花顺对账，先过 R6。
  2. 翻你的 CSV：找单日跌幅 ≥9% 的交易日，确认引擎在这些日子前后的持仓与成交符合四定律。
  3. 思考题：引擎里"跌停卖单作废"意味着该日你继续持有、次日再试——这与现实里"挂跌停价卖出排队"差在哪？哪个对你更不利？（提示：排队位置。）
  4. 强制绑定测试（验证代码路径真的通）：把 LimitPct 改成 0.01、StampTax 改成 0.005 重跑，数字应该明显变化；确认后改回真实值。四定律在 510300 上"不绑定"不等于"没实现"。

自由回忆（隔天再做一遍效果更好）

不看上文：① 四条定律各配一句"若忽略会怎样"；② A 股个人的策略空间一句话；③"涨停禁买、跌停禁卖"的现实直觉是什么。

① T+1→隔夜风险被低估；涨跌停→假成交；成本单边印花→收益虚高；禁做空→空头腿虚增收益。② 只做多 + 空仓两状态 + 日线以上。③ 涨停买方长队、跌停卖方长队，你的单在队尾，保守回测按"轮不到成交"处理。
