双均线与你的第一次作弊

上一课你造了基准（买入持有），今天给它装上大脑：一个真正的信号策略。然后——做一件平时绝对禁止的事：亲手作弊一次，让未来函数把收益虚增给你看。见过假货，才认得出真货。

双均线：最简单的趋势规则

规则一句话：短期均线上穿长期均线（金叉）买入，下穿（死叉）卖出。

信号条件（每日收盘后计算）动作
金叉SMA50 从下方穿越到 SMA200 上方买入（95% 仓位）
死叉SMA50 从上方穿越到 SMA200 下方清仓，空仓等待

对照《炒股的智慧》：陈江挺说"看势、等临界点"。均线交叉是对"势"最粗糙的机械代理——作者观点它看不见临界点，但不会情绪化，代价是滞后。这正是量化与 discretionary 交易的分野：放弃聪明，换取可验证。

在掘金里写出来

相对第 2 课，只有两处新东西：① 自己维护一个滚动收盘价窗口来算均线（掘金 C# SDK 不强制你用内置指标，先用最笨的办法把逻辑看清）；② 仓位状态机加上了出边——_prevSign 记住上一刻的方向，翻转才动作。

SmaCross.cs — 在第 2 课工程里新增一个策略类

using System.Collections.Generic;
using System.Linq;
using GMSDK;

public class SmaCross : Strategy
{
    private const string Symbol = "SHSE.510300"; // 沪深300ETF
    private readonly List<double> _closes = new List<double>();
    private int _prevSign = -1;                  // -1 空仓/均线下方，+1 持仓/均线上方

    public SmaCross(string token, string strategyId, StrategyMode mode)
        : base(token, strategyId, mode) { }

    public override void OnInit()
    {
        Subscribe(Symbol, "1d");
    }

    public override void OnBar(Bar bar)
    {
        _closes.Add(bar.close);
        if (_closes.Count < 200) return;         // 200 日均线还没攒够数据

        double fast = _closes.Skip(_closes.Count - 50).Take(50).Average();
        double slow = _closes.Skip(_closes.Count - 200).Take(200).Average();
        int sign = fast > slow ? 1 : -1;

        if (sign != _prevSign)                   // 状态翻转：金叉或死叉
        {
            OrderTargetPercent(Symbol, sign == 1 ? 0.95 : 0.0,
                PositionSide.PositionSide_Long,
                OrderType.OrderType_Market);
            _prevSign = sign;
        }
    }
}

Program.cs 不用重写：把 new BuyAndHold(...) 换成 new SmaCross(...)，回测参数沿用第 2 课。十年下来交易次数应该在个位数到十几次——这就是趋势策略的样子：大部分时间空仓或持有不动。

掘金的回测撮合模式决定了信号与成交的时序：用"下一根 K 线开盘"档，平台替你守住诚实线；改成"当前 K 线收盘"档，你就自己打开了作弊开关。参数在终端回测参数里查看，官方说明见 策略回测与绩效。

作弊现场：未来函数虚增收益

未来函数：决策用了决策时点不可能知道的信息。经典形态是"用今日收盘算出的信号，在今日成交"——你用了今天收盘才知道的信息，却假定今天就能按这个价格买到，等于时空套利。

别把双均线拿去实盘。它是教学载体和基准挑战者。第 4 课你会系统学到：双均线参数是"自由度"，自由度越多，越容易把历史噪声拟合出花来。
