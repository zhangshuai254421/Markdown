* NAPKIN | 餐巾纸

** 公式

#+begin_example
+--------------------------------------------------------------------------+
|                                                                          |
|   长期利润 = 出手次数 x [ 胜率 x 大利润 - (1-胜率) x 小止损 ]            |
|                                                                          |
|   正期望不靠"预测更准", 靠三件可控的事:                                  |
|     1. 少出手   -- 只在临界点下单                                        |
|     2. 小止损   -- 亏损固定在 ~8% 以内(可控项!)                          |
|     3. 让利跑   -- 盈利不设目标价, 吃完整段势                            |
|                                                                          |
+--------------------------------------------------------------------------+
#+end_example

炒股赚的不是"预测对的钱", 是"错时亏得小、对时赚得大"的赔率差;
把唯一完全可控的变量(单笔最大亏损)锁死, 期望值自然转正。

** 一句话

炒股是等待的艺术: 不预测只应对 -- 看势、等临界点、错则小亏离场、对则让利润奔跑, 靠纪律而非聪明活下来赚钱。

* ROUND 1: SKELETON | 骨架扫描

"这本书在说什么"

**核心问题**: 一个没有内幕消息、没有资金优势、只有小钱和正常智商的普通人, 如何在股市中长期存活并持续盈利? 炒股这件事的本质到底是什么?

**核心答案**: 炒股是概率与心理的博弈 -- 价格运动有"势", 在临界点用小止损赌大利润, 长期盈利靠纪律而非聪明或预测。

**章节骨架**:
1. 引言: 股市是筹码钞票博弈场
2. 股票运动规律: 势决定一切
3. 成功的要素: 败而不倒、追求卓越
4. 分析方法: 技术面重于价值面
5. 判断大市: 先看潮水的方向
6. 学习的过程: 先交学费再谈赚
7. 何时买: 等临界点突破
8. 何时卖: 截断亏损让利奔跑
9. 资金管理+心理: 纪律即生命线
10. 大师论炒股: 站在巨人肩上

**论证结构**: 案例+归纳型。以作者华尔街实战经历与大师兴衰轶事归纳出操作规则, 再用人性论(贪婪/恐惧/希望)演绎"规则为什么必须如此"; 全书无公式无回测, 是经验性而非实证性论证。

* ROUND 2: DISSECTION | 血肉解剖

"凭什么这么说"

**论证链**:

#+begin_example
千万交易者的贪/惧/希望驱动市场
   --> 价格运动呈"势", 势一旦形成有自我强化的惯性
   --> 势的启动与转折集中于"临界点"(阻力位突破/支撑跌破)
   --> 在临界点出手: 对 = 惯性带来大行情; 错 = 假突破, 可小亏离场
   --> 机械止损(~8%) + 不设目标价 => 每笔交易天然"亏小赚大"
   --> 资金管理保证任何单笔亏损不伤及本金根本
   --> 长期重复足够多次 => 正期望 => 盈利靠执行纪律, 不靠预测
#+end_example

**关键证据**:
1. 利弗莫尔的四起四落: 华尔街最天才的交易者最终破产自杀 -- 不缺聪明、缺纪律, 全书最强的反面教材, 论证"规则 > 判断"。
2. 作者的实盘对照: 同一个人、同一个市场, 从随意交易的持续亏损, 到建立"临界点+固定止损"规则后转为稳定盈利 -- 一个近似单变量的自我实验。
3. 散户的统计命运("七亏二平一赚"): 追高杀跌是人性的默认设置, 不设规则者必然成为规则的对手盘 -- 反证规则是活下来的前提而非优化项。

**隐形假设**:
- 历史会重演: 技术形态与临界点在未来仍有统计效力
- 市场短期由情绪驱动, 情绪模式稳定, 存在可利用的持续性规律
- 交易成本低、执行快、可自由做空(作者的参照系是 1990s 美股 day trading)
- 读者拿得出"输光了也不影响生活"的学费本金和时间

**边界条件**:
- 制度不适配: A股 T+1、涨跌停、做空受限, 书中打法需要变形后才能落地
- 有效性衰减: 程序化交易普及后, 经典突破形态被算法抢跑, 临界点胜率下降
- 执行者失效: 没有纪律的人套用任何系统都亏损 -- 方法的前提是人本身
- 市况依赖: 长期单边牛市里频繁交易跑输简单持有(作者路线与巴菲特路线是两种模式, 不可比收益)
- 操纵环境: 小盘股的图形可被庄家画出来, 临界点沦为诱多陷阱

* ROUND 3: SOUL | 灵魂提取

"还能怎么用"

**作者盲点**:
- 临界点的胜率从未给出统计验证 -- 全书是经验之谈而非回测结果, 读者只能"信"而不能"证"
- 幸存者偏差: 作者本人是幸存者, 交完学费离场的人没有写书
- 交易成本、税负、滑点对短线策略的侵蚀着墨极少
- 时代局限: 算法交易已改变临界点的微观结构, 书中对手盘与今天不同
- 基本面/估值被边缘化, 方法难以迁移到长期投资的语境

**跨域映射**:
- 物理学: "势" = 动量(momentum); 临界点 = 相变(phase transition)的临界态
- 复杂系统: 临界点 = 分岔点(bifurcation), 大涨大跌是情绪的非线性涌现
- 风险投资: 让利润奔跑 = 押注幂律(power law), 回报来自极少数大赢家
- 期权思维: "亏小赚大"本质是做多凸性(convexity)的回报结构
- 行为金融: 贪/惧/望 = 处置效应与前景理论的通俗版
- 信息论: 等临界点 = 只在信噪比最高的时刻采样, 平时保持空仓降噪

**知识连接**:
- 状态机: 买卖规则天然是状态机(空仓->持仓->止损/止盈), 可写成代码防手贱 -- 与工程里的状态机建模(如 AlarmStateMachine)同一套方法
- 止损 = fail-fast: 工程学"尽快失败、清晰失败", 交易学"尽快认错、小额认错"
- 回测 = 回归测试: 规则先在历史数据上跑通, 再上真钱; 交易日志 = 测试用例
- 期望值思维 = 性能预算: 不问"这一次行不行", 问"长期平均是否为正"
- 仓位控制 = 凯利公式的朴素保守版

**行动触发**:
1. 下单前三行检查单: 入场触发(临界点怎么定义)、止损价、仓位 -- 写不出来就不买
2. 用可全损的小资金交学费, 每笔交易记日志(理由/情绪/结果), 每月复盘胜率与盈亏比
3. 把个人交易规则写成代码或 checklist(程序员专属优势): 单笔风险 <= 总资金 2%
4. 区分两类钱: 短线博弈用本书规则; 长期储蓄走指数定投 -- 别用两套逻辑管同一笔钱
