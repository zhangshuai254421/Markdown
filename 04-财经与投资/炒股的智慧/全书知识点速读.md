## 一、炒股的挑战:散户为什么亏钱

### 1.1 股市是一个"特殊的赌局"

- 与赌场不同:你可以**选择不下注**(空仓等待)、可以**随时离场**(卖出止损)、赔率(涨跌空间)自己会变。
- 所以赢的关键:**只在胜算大、赔率有利时才出手**,其余时间拿现金等待。
- 炒股是**艺术不是科学**:没有标准答案,追求的是"总体赚钱",不是"每次都对"。

### 1.2 一般股民失败的六大人性弱点(全书立论基础)

| 人性弱点 | 在股市中的表现 | 后果 |
|---|---|---|
| **讨厌风险** | 小赚就急着卖(怕利润飞了),大亏却死扛(不愿认错) | 截断利润,放跑亏损(完全做反) |
| **急功近利** | 频繁交易、满仓博短线、想一夜暴富 | 手续费磨损 + 大错一次清零 |
| **好自以为是** | 跌了不认错,反而给自己找理由 | 小亏拖成大亏 |
| **好跟风** | 听消息、跟朋友买、追涨杀跌 | 买在顶部,卖在底部 |
| **因循守旧** | 死抱亏损股"等回本" | 资金被套死,错过机会 |
| **报复心理** | 亏了想扳本,加倍下注 | 越赌越亏,恶性循环 |

### 1.3 市场情绪是反向指标

- 华尔街调查:**散户买入的主因是"股票在涨",卖出的主因是"股票在跌"**——而不是理性分析。
- 街头巷尾都谈股市赚钱 → 推动资金已用尽 → 大市见顶;人人恐惧、该卖的都卖了 → 跌势将尽。
- **在别人贪婪时恐惧,在别人恐惧时贪婪。**

## 二、股票分析的基本知识

### 2.1 基础分析(基本面)

> 核心信念:长期而言,股价决定于公司的**固定资产和盈利能力**。
> (详细笔记见同目录《阅读笔记.md》《导致股价上涨的三因素.md》《成本收益比率_PE_介绍.md》)

- **大环境 8 因素**(利率、税收、汇率、银根、经济周期、通胀、政治、产业政策):影响宏观,但太复杂,实用价值有限。彼得·林奇:"我每年花在经济大势上的分析不超过 15 分钟。"
- **小环境 5 因素**(营业收入、盈利、固定资产、同类公司对比、品牌):这才是选股重点,需能读懂财报、警惕会计水分。
- **推动股价上涨三因素**:①盈利增长(核心,要看增速与加速度,且必须有销售收入同步支撑)②新产品/新模式(爆发催化剂)③公司回购股票(信心信号+降低PE)。
- **PE 的正确用法**:PE 低不等于便宜,PE 高不等于贵——增长速度才是关键(微软上市时 PE 超 100,13 年涨百倍)。

### 2.2 技术分析(择时工具)

> 基本面告诉你"买什么",技术面告诉你"什么时候买、什么时候卖"。

**(1)趋势(走势)——技术分析的核心**

| 趋势 | 特征 | 操作含义 |
|---|---|---|
| 升势 | 高点、低点不断抬高 | 只在升势中做多 |
| 跌势 | 高点、低点不断降低 | 不抄底,空仓等待 |
| 无趋势(盘整) | 横向震荡 | 观望,等突破 |

- 走势线(趋势线):升势中连接依次抬高的低点画出趋势线;**有效跌破趋势线 = 升势可能结束**。
- 口诀:**趋势是你最好的朋友,顺势而为,绝不逆势。**

**(2)支撑线与阻力线**

- 阻力线=前期高点/成交密集区,支撑线=前期低点/成交密集区。
- **角色互换**:阻力被向上突破后变成支撑;支撑被跌破后变成阻力。
- 应用:买在"向上突破阻力线"处,止损设在阻力线下方——**离场点和入场点距离近,风险小**。

**(3)反转形态:双肩图与头肩图**

- 头肩顶(中间高点最高、两侧稍低):涨势结束的警报,**跌破颈线(两肩低点连线)确认卖出**。
- 双顶/双肩图:两次冲击同一高位失败 → 上涨动能耗尽。
- 意义:不预测顶,只在**形态确认跌破后**行动。

**(4)平均线(均线)**

- **200 天均线是牛熊分界线**:股价站在 200 天线上且均线走平向上 → 多头市场;跌破且均线向下 → 空头市场。
- 均线代表市场平均成本,是多空力量的平滑观察窗。

**(5)成交量(量的确认)**

- 向上突破阻力线/创新高时,**必须放量**才算有效;缩量突破多为假突破。
- 量是价的"燃料":价升量增=健康,价升量缩=警惕。

### 2.3 华尔街的家训(操作铁律,全书精华)

| # | 家训 | 一句话解释 |
|---|---|---|
| 1 | **止损,止损,止损** | 第一原则。亏损是交易的成本,必须限定在小额 |
| 2 | **分散风险** | 不要把命运押在一只股票上 |
| 3 | **避免同时持有太多股票** | 太多看不过来,3~5 只以内为宜 |
| 4 | **有疑问的时候,离场** | 看不懂就不参与,现金不丢人 |
| 5 | **忘掉你的入场价** | 持有/卖出只看走势对不对,不看自己成本 |
| 6 | **别频繁交易** | 交易越频繁,期望值越低 |
| 7 | **不要向下摊平** | 亏损时加码 = 错上加错(与"报复心"作战) |
| 8 | **别让利润变成亏损** | 浮盈后把止损位提到成本之上,保住胜利果实 |
| 9 | **跟着股市走,别跟朋友走** | 不听消息、不跟风;市场对,消息不一定对 |
| 10 | **别把"跌了很多"当买入理由** | 便宜可以更便宜;也别把"涨了很多"当卖出理由 |
| 11 | **该卖的时候要卖** | 不追求卖在最高点,犹豫的代价很高 |
| 12 | **先定计划,再进场** | 买之前就想好在哪止损、什么情况离场 |

## 三、成功的要素:怎么买、怎么卖、怎么管钱

### 3.1 何时买股票——"临界点"买入法

**买入前提(四个条件尽量同时满足):**

1. 大市处于升势(牛市/至少不是跌势)
2. 个股处于升势(高点低点抬高)
3. 股价**刚刚向上突破阻力线 / 突破前高 / 创新高**(即"临界点")
4. 突破时**成交量放大**确认

**为什么买在临界点(这是全书最核心的操作思想):**

- 假突破 → 股价很快跌回阻力线下 → **立刻止损,损失很小**;
- 真突破 → 趋势展开 → 收益很大。
- 好买点 = **离止损点近的买点**(风险收益比最优)。
- 反面教训:**不要在跌势中抄底**,"等它便宜"不如"等它转强";底是走出来的,不是猜出来的。

**买前必答三问:** 趋势向上吗?买点离止损点近吗?止损位在哪(进场前就定好)?

### 3.2 何时卖股票——卖比买难

**卖出四种情形(触发任何一条就执行,不犹豫):**

1. **硬止损**:跌破买入前定好的止损位 → 无条件卖,不找理由
2. **保利止损**:买入后上涨,把止损位提到成本之上 → 即使回落也不把盈利变亏损
3. **趋势反转**:有效跌破走势线/支撑线,或出现头肩顶/双顶并跌破颈线 → 卖
4. **大市转弱**:大盘由牛转熊,个股很难独善其身 → 减仓离场

**两条纪律:**

- 买对了就让利润奔跑(不急止盈),买错了立刻认错(不拖)——**"截短亏损,让利润奔跑"**(Cut loss short, let profit run)。
- 卖出后涨了不后悔,卖出后跌了不炫耀——按规则执行就是对的。

### 3.3 资金管理(注码决定生死)

1. **不要一次满仓**:分批进场,永远保留现金;空仓等待也是一种操作。
2. **单笔风险要小**:每次交易的最大亏损(买入价-止损价的差额×股数)只占总资金的小比例,错了不伤筋骨。
3. **亏损时减注**:连亏时缩小注码甚至停止交易,先冷静复盘。
4. **盈利时才加码**:走势证明你对了再加(金字塔式,越加越少),绝不向下摊平。
5. **风险收益比**:只在"可能赚 3 块、最多亏 1 块"的时机出手;赔率不划算就不下注。

### 3.4 成长路径(从新手到行家)

- 用**小钱练手**,把学费控制在可承受范围;亏小钱买经验是必经之路。
- **记交易日记**:每笔买卖的理由、情绪、结果,定期复盘——经验比运气值钱。
- 逐步形成**适合自己性格的炒股方法**,别人的方法照搬必失败。
- 炒股成功是马拉松:先学会**不亏大钱**,赚钱只是时间问题。

## 四、心态与炒股的智慧(全书总结)

1. **炒股是概率游戏**:不求每笔都对,只求错时亏小钱、对时赚大钱(期望值为正)。
2. **纪律高于预测**:计划你的交易,交易你的计划;市场永远没有错,错的只能是你。
3. **两大敌人是贪和怕**:贪 → 追高、不止盈、频繁交易;怕 → 不敢买突破、不敢止损、拿不住好股。
4. **耐心是稀缺资源**:好机会是等出来的,不是找出来的;一年只需几次好交易。
5. **合理预期**:每年稳定的复利(如 20%~30%)已极其优秀,别想一夜暴富。
6. **独立思考**:消息到你耳朵里时,价格早已反映;跟着别人走注定平庸。
7. **接受失败**:亏损是这门生意的成本,错了就改,别和市场赌气。
8. **生活大于炒股**:锻炼、家庭、平常心;心态崩了技术再好也没用。

## 五、实操速查:一笔完整交易的流程

```
① 选股:基本面过关(盈利增长/新产品/回购,收入支撑盈利)
   ↓
② 等待:个股+大盘处于升势,股价临近阻力线(不满足就空仓等)
   ↓
③ 计划:进场前写好——买入价、止损价、仓位大小
   ↓
④ 买入:放量突破临界点时买,分批进场不满仓
   ↓
⑤ 持有:走势没破坏就拿着,让利润奔跑;涨了就把止损提到成本上
   ↓
⑥ 卖出:触发止损/跌破趋势线/头部形态/大盘转弱 → 立即执行
   ↓
⑦ 复盘:记日记,只评价"是否守了纪律",不评价"这一笔赚亏"
```
