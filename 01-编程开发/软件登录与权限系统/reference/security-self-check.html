桌面登录权限安全自查单22 项 · 按五环节排列 · 每项都标了依据 · 可打印

用法：逐项核对自家软件，勾「符合 / 不符合 / 不适用」，不符合的当场写下差距。依据列：OWASP = 各速查表与 ASVS；NIST = SP 800-63B-4；等保 = GB/T 22239-2019（条款为要点转述，测评以官方原文为准）；课程 = 对应课次。

A · 凭据存储（第 2 课）

检查项依据怎么查结果
1. 密码用加盐慢哈希存储（PasswordHasher 调 ≥60 万次 / bcrypt cost ≥10 / Argon2id）OWASP 密码存储 / 课程②看注册/改密代码与密码列内容□
2. 无明文、无可逆加密、无 Base64 存密码OWASP 密码存储搜 Encrypt/AES/Base64 出现在密码相关代码□
3. 哈希参数按当前算力校准过（单次 <1 秒）OWASP / NIST实测一次登录校验耗时（第 2 课实验台）□
4. 旧格式密码有「登录时升级」迁移路径OWASP 密码存储找 SuccessRehashNeeded 处理□

B · 登录窗口（第 3 课）

检查项依据怎么查结果
5. 失败提示统一为「用户名或密码错误」OWASP 认证用不存在的账号试一次□
6. 连续失败有简单锁定（如 5 次锁 5 分钟）OWASP 认证 / 等保 8.1.4.1 b)连错 5 次看行为□
7. 登录成功与失败都写审计（含尝试的账号名）OWASP 认证 / 等保安全审计查审计表登录记录□

C · 密码策略（第 2、3 课）

检查项依据怎么查结果
8. 最小长度：有 MFA ≥8 位；无 MFA ≥15 位；上限 ≥64 位NIST 800-63B-4看校验代码□
9. 弱口令黑名单（常见口令拦截）NIST / OWASP用 123456 注册一次□
10. 无强制组合规则；「定期更换」按测评条款沟通后处理NIST 800-63B-4 / 等保 8.1.4.1 a)看注册校验与有效期字段□
11. 无安全问题找回（KBA）OWASP / ASVS找回流程走一遍□

D · 会话与凭据保护（第 3 课）

检查项依据怎么查结果
12. 会话只放身份不放密码；有「退出/切换账号」入口课程③ / 等保 b)看 UserSession 与主界面□
13. 无操作锁屏回登录窗（工业现场建议 30 分钟）等保 8.1.4.1 b)「超时自动退出」挂机 31 分钟再看□
14. 多机连库：账号表集中管理；新登录顶掉旧终端；数据库账号只给业务表读写课程③ / OWASP 授权看账号表位置与数据库账号权限□

E · 授权控制（第 4、5 课）

检查项依据怎么查结果
15. 默认拒绝：新用户不授角色时无任何可用功能OWASP 授权建一个测试账号不授角色□
16. 权限只经角色发放：无用户直连表、无人名硬编码OWASP 授权 / 课程④搜 UserPermissions 与 if (userName==□
17. 全部「会改变什么」的命令挂了权限点（CanExecute），入口清单核对过OWASP 授权 / 课程⑤对照第 5 课作业的入口清单□
18. 职责分离：「分配权限」与「查看审计日志」不同角色NIST RBAC 约束层看权限矩阵□
19. 默认账户已改名或禁用；多余/过期账号及时删除等保 访问控制（转述）列全部账号核对□

F · 审计留存（第 1、5 课）

检查项依据怎么查结果
20. 审计覆盖每个用户；记录含时间、用户、动作、对象、结果等保 安全审计（转述）抽 3 类操作各查一条日志□
21. 四类必记：改配置、删数据、登录成败、权限变更；「拒绝的操作」也记课程⑤故意输错密码后查日志□
22. 审计表只增不删（无「清空」入口）；留存 ≥6 个月；多机连库放中央库等保 /《网络安全法》第 21 条看表权限与归档策略□
差距清单怎么写 每个不符合项一行：编号 + 现状 + 依据编号 + 整改方向 + 责任人/期限。示例：「1 现状：密码列存明文 → 依据 A-1 → 整改：PasswordHasher 调 60 万次 + 登录时升级迁移，随下版本」。这份清单同时就是等保整改台账的雏形。
