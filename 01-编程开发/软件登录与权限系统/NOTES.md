- 全中文教学，术语首次出现给英文原文
- 技术栈：C#/.NET，WPF 客户端 + 局域网服务端（C/S 工业软件，公司项目背景）
- 双目标（2026-10-16 确认）：① 工作项目要用 ② 系统补齐知识体系 → 课件里每个概念都要落到「你自家软件怎么做」
- 课件沿用课程库统一风格：Tufte 风 `assets/style.css`（本课程 accent = 深青 #0f766e）+ `assets/quiz.js` 测验组件（data-quiz JSON 契约）

- 已有课程习惯：GLOSSARY.md 术语表先行，课程间术语一致

## 教学决策
- 标准主线三条：OWASP（怎么落地）+ NIST SP 800-63B-4（为什么这样做）+ 等保 2.0 GB/T 22239-2019（合规底线）；OAuth/OIDC 只做地图级了解（MISSION out of scope）
- 起点判断：认证授权零基础起步（未见相关学习记录），第一课从认证/授权/审计的概念区分 + 登录五环节全景切入
- 参考卡先行：用户第一问就是「有什么标准」，所以 0001 课配套 `reference/standards.html` 标准速查卡
- 可复用组件：`assets/hash-lab.js` 密码哈希实验台（WebCrypto 计时+盐演示）；`assets/token-lab.js` JWT 令牌实验室（HMAC 签发/验签/篡改/自签）；`assets/bruteforce-lab.js` 爆破计算器（算术演示四类防护策略）；`assets/rbac-lab.js` 角色权限矩阵评审（10权限×4角色+规则引擎）；`assets/authz-lab.js` 越权演示（垂直/水平越权脚本化场景）
- 全部 7 课已发布（2026-10-17）：0001 概念地图 / 0002 密码存储 / 0003 会话令牌 / 0004 登录防护 / 0005 RBAC / 0006 强制授权 / 0007 等保自查结课；参考卡：standards.html（标准速查）+ security-self-check.html（29 项自查单）
- 标准冲突处理（0007 教学决策）：等保「定期更换密码」vs NIST 反对 → 课程立场：测评按条款执行弱化版周期 + 留存书面沟通记录（依据 NIST + 补偿措施黑名单/高熵/泄露监测）
- 课程边界（已在 0007 诚实清单声明）：TLS 部署细节、主机/数据库层加固、备份安全——用户带回差距清单后可能成为续课或答疑方向
