await 状态机速查卡

来源:第 0006 课 主推阅读:Toub · How async/await really works

一句话:await 不是暂停,是拆段 + 登记 + 提前返回; 恢复不是魔法,是完成者调用 MoveNext()。这张卡压缩全部机械细节。

一、源码 → 编译器产物对照

你写的编译器变成
async 方法嵌套状态机类(含 MoveNext())+ 薄外壳方法
跨 await 的局部变量状态机的公共字段(提升 hoisting)
await 之前的代码case -1 段
await 那一行IsCompleted 分岔 + 登记续延 + return
await 之后的代码case 0 段
方法的 returnBuilder.SetResult(...) → 欠条 RanToCompletion
抛出的异常Builder.SetException(ex) → Faulted;OCE → Canceled

二、慢路径时序(欠条未完成)

步动作谁在做
1外壳创建状态机,Builder.Start 点火 → MoveNext() 首次执行调用者线程
2段 1 跑到 await;拿 GetAwaiter(),问 IsCompleted → false调用者线程
3State=0;登记续延:AwaitUnsafeOnCompleted(ref awaiter, ref this)调用者线程
4return:调用者拿到 Task;栈帧销毁,变量已在状态机字段里调用者线程
5欠条完成 → 执行续延 → MoveNext() 再入,跳到 case 0;取值后 SetResult完成者线程(默认内联)

快速路径(欠条已完成)

IsCompleted == true → 不登记、不挂起、goto 直接走下一段: 零注册零调度。缓存命中、已完成的数据源都走这条——await 已完成的 Task 几乎免费。

三、角色表

角色一句话职责
State段号。首次 -1;过一个 await 存 0;"下次从哪段继续"的记号
Awaiter欠条的读取器:IsCompleted 问完成;GetResult() 取值/重抛
Builder出票人代理:开欠条(Task)、销账(SetResult/SetException)
MoveNext()方法体全体;每被调一次,从 State 指的段继续
AwaitUnsafeOnCompleted登记续延("完成后调 MoveNext");Unsafe = 不经 awaiter 流 ExecutionContext
GetResult()双职责:成功 → 返回值;欠条 Faulted/Canceled → 重抛异常
SetResult / SetException状态流转扳机(0005 的三终态由此进入);SetException 遇 OCE 落 Canceled

两个高频追问

① 调用堆栈为什么是断的?每次真实暂停 = 一次 return + 一次被 MoveNext 重新拉起, async 方法出现在不连续的两截栈之间。② 零分配是怎么回事?真实产物中状态机是 struct:快路径全程不逃逸、不上堆;慢路径才装箱存活。骨架用 class 讲结构,语义相同。

四、面试自测六问

① await 到底暂停了什么? 什么都没暂停。方法被拆段,遇未完成欠条则登记续延并 return;线程正常离开,调用者立刻拿到欠条。
② 为什么 await 之后还能用之前的局部变量? 变量被提升为状态机字段。栈帧随 return 销毁,跨暂停存活的变量必须搬到堆上的状态机里。
③ "恢复"的执行者是谁?在哪个线程? 欠条的完成者执行续延 → 调 MoveNext()。默认内联在完成者线程(TCS 默认语义;0007 讲 SynchronizationContext 如何改变归属)。
④ await 处抛出的异常从哪来? GetResult() 重抛欠条里存的异常。SetException 决定终态:普通异常 → Faulted;OCE → Canceled(TAP 规则)。
⑤ await 已完成的 Task 有开销吗? 几乎没有:快速路径直接顺序走完,不注册续延、不调度、不切线程。热路径大量 await 由此成立。
⑥ async 方法的 Task 是谁创建的? Builder。外壳方法里 Builder.Start 点火后由 Builder.Task 交出——async 方法自己就是出票人(0001 四种出票人第一种)。

五、术语表增量

状态机 state machine编译器为 async 方法生成的类/结构体,含 State、字段、MoveNext
MoveNext方法体的续延入口;每次调用推进到 State 记住的段
提升 hoisting跨 await 的局部变量从栈帧搬到状态机字段
续延 continuation"欠条完成后要做的事";在状态机里就是"再调一次 MoveNext"
外壳方法 stub保留原签名的薄方法:建状态机 → Start 点火 → 交出 Builder.Task
快速路径 fast path欠条已完成时的直通道:不登记、不挂起、不调度
重抛点await 表达式:消费欠条异常的唯一出口(GetResult 重抛)
