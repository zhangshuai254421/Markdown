事件等待与异步初始化速查卡

口诀:先订阅,后检查;到达即退订;销账用 Try

模式一:事件 → Task(生产版,含取消)

public static Task WaitForConnectedAsync(
    MessageClient client, CancellationToken ct = default)
{
    var tcs = new TaskCompletionSource(
        TaskCreationOptions.RunContinuationsAsynchronously);

    void OnConnected(object? s, EventArgs e)
    {
        client.Connected -= OnConnected;        // 到达即退订
        tcs.TrySetResult();                     // 竞速语义
    }

    client.Connected += OnConnected;            // ① 先订阅

    if (client.IsConnected)                     // ② 后检查(兜底)
    {
        OnConnected(client, EventArgs.Empty);   // 复用清理逻辑
        return tcs.Task;
    }

    if (ct.CanBeCanceled)                       // ③ 取消 → 退订 + 注销欠条
        ct.Register(() =>
        {
            client.Connected -= OnConnected;    // 取消也要退订!否则照旧泄漏
            tcs.TrySetCanceled(ct);
        }, useSynchronizationContext: false);

    return tcs.Task;
}
四步骨架防的是什么
① 先订阅事件在"检查→订阅"之间触发,无人接住 → 永久悬挂
② 后检查事件早已发生过的场景
到达即退订长寿事件源 + lambda 捕获 tcs → 引用链泄漏
销账用 Try"已连接"分支与事件分支、取消分支竞速

模式二:单飞异步初始化(single-flight)

private TaskCompletionSource<MessageClient>? _initTcs;

public Task<MessageClient> GetClientAsync()
{
    if (_initTcs is null)
    {
        var tcs = new TaskCompletionSource<MessageClient>(
            TaskCreationOptions.RunContinuationsAsynchronously);
        if (Interlocked.CompareExchange(ref _initTcs, tcs, null) is null)
            _ = InitializeAsync(tcs);           // 唯一启动者
    }
    return _initTcs.Task;                        // 所有人 await 同一张欠条
}

private async Task InitializeAsync(TaskCompletionSource<MessageClient> tcs)
{
    try
    {
        tcs.SetResult(await CreateAndConnectAsync());   // 唯一完成路径 → Set*
    }
    catch (Exception ex)
    {
        tcs.SetException(ex);                    // 失败也广播
        _initTcs = null;                         // 允许下次重试,不缓存失败
    }
}

亲戚与取舍

Lazy<Task<T>>最简;但失败会被 Lazy 缓存(默认),无重试语义
手写单飞 TCS(本课)失败重试、无依赖;每行可知其所以然
Microsoft.VisualStudio.Threading.AsyncLazyVS/Roslyn 标准件;带 JoinableTaskFactory 上下文集成
ASP.NET Core IHostedService初始化属于应用生命周期时,交给框架,启动顺序由 Host 管理

术语表补充

单飞 single-flight并发触发时只允许一个执行者启动,其余汇入同一结果
广播一张欠条被任意多消费者 await(欠条终态不可变所赐)
EAP事件式异步模式(Event-based Asynchronous Pattern),TCS 是把它包成 Task 的官方桥
useSynchronizationContext: false令牌回调不回投递到捕获的上下文,库代码里的惯例防死锁
