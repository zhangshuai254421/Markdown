# 基线水平校准:"皮毛"级 async/await 用户

用户自述有多 .NET 经验,日常熟练使用 async/await(接口调用、EF 查询等),自评"了解机制皮毛":知道线程池、ConfigureAwait、异步死锁现象,大致了解 SynchronizationContext,但从未系统梳理。动机四合一:读源码、解决工作问题、系统补课、面试准备。时间预算:每天 15–30 分钟。

**Implications**:不需要教 async/await 基础语法,可从"Task 心智模型"直接切入;但涉及 SynchronizationContext / 状态机时要按"听过但没通透"来教——先建立准确模型再纠偏。课程需保持每课的面试视角标注,并依靠间隔复习钩子对抗碎片时间带来的存储强度不足。
