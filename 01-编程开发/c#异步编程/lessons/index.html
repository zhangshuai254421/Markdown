C# Async/Await · Course Index

C# 异步编程 九课，从「await 不是等线程」的心智模型，一路下钻到状态机、SynchronizationContext、IValueTaskSource 与异步流。建议按顺序学，每课约 20–30 分钟。

  1. Lesson 0001 · 心智模型 async 不是多线程 await 是「注册续延」，不是「开新线程等结果」。理解一切异步的承重墙。
  2. Lesson 0002 · 编译器层 编译器把 async 方法变成了状态机 MoveNext、Builder、await 处的「挂起与恢复」到底长什么样。
  3. Lesson 0003 · 运行时 续延跑在哪：SynchronizationContext 与死锁 .Result 卡死 UI 的根源，以及 ConfigureAwait 的真实作用。
  4. Lesson 0004 · 实战雷区 异常去哪儿了：async void、fire-and-forget 与取消 异常如何沿 Task 传播、async void 为什么会崩进程、取消怎么传到底。
  5. Lesson 0005 · 运行时 Task 家族与线程池 Task / Task<T> / ValueTask 怎么选，Task.Run 的代价与线程池饥饿。
  6. Lesson 0006 · 运行时内部 IValueTaskSource：让异步完成也零分配 ValueTask 复用完成的底层机制，高性能库代码的写法与风险。
  7. Lesson 0007 · 现代 C# 异步流（IAsyncEnumerable） await foreach、逐项消费、背压——串口/设备持续上报数据的正确姿势。
  8. Lesson 0008 · 运行时内部 ExecutionContext 与 AsyncLocal 上下文如何随续延流动，日志 TraceId 为什么能跨 await 保持。
  9. Lesson 0009 · 收尾 实战决策清单 把八课收束成写代码、评审、排障时直接可用的判断规则。
  10. Reference 词汇表 续延、状态机、承诺任务……全课程统一术语。
